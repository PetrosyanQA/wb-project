# Մարքեթինգի մոդուլ

Նպատակը՝ քարտ, որը **սեղմում են** (CTR) և **գնում են** (փոխարկում)։ Ամեն թիվ ու պնդում ապացուցվում է տվյալներով։

Գործարկում՝ `/marketing <նիշա> <ապրանք>` (`.claude/commands/marketing.md`) կամ ձեռքով ստորև նշված հրամաններով։

## Գործիքներ

| Քայլ | Հրաման | Աղբյուր | Արժեք |
|---|---|---|---|
| WB մրցակիցների պատկերասրահ, rich, բնութագրեր | `python -m src.mkt wb --niche 249 --top 12` | WB CDN + Saleflow products500 | 0 |
| Միջազգային (Amazon US) քարտեր | `python -m src.mkt amazon --niche 249 --query "pull up assistance bands" --detail 6` | Bright Data | ≈ 7 կրեդիտ |
| Աուդիտ + կոնտակտային թերթեր | `python -m src.mkt audit --niche 249` | ↑ | 0 |
| Լուսանկար / ֆոտոսեսիա / ֆոն / upscale | `python -m src.mkt gen --niche 249 --mode freeform\|photoshoot\|remove-bg\|upscale --image <ֆայլ> --brief <txt>` | Saleflow Photo Editor | սակագնում |
| Սլայդ՝ ճշգրիտ ռուսերեն տեքստով | `python -m src.mkt compose marketing/249/slides/s1.json` | մեր կոդը (PIL) | 0 |
| WB-ի պահանջները լուսանկարների նկատմամբ | `docs/wb_help/how-to-add-items-in-your-store/...` | Справочный центр | 0 |

Կառուցվածքը.
- **Հում տվյալներ** (git-ում չեն)՝ `data/raw/mkt/<նիշա>/{wb,amazon}/`։
- **Արդյունքներ** (git-ում)՝ `marketing/<նիշա>/`. աուդիտ, բրիֆներ, `slides/*.json`, պատրաստի սլայդներ, `generated/`։

## Մեթոդիկա (8 քայլ)

1. **Տվյալներ.** products500, բողոքներ, keywords. ինչ են գնում, ինչից են դժգոհում, ինչ են փնտրում։
2. **WB-ի վիզուալ հետախուզում.** top-12 ըստ եկամտի։ Ամեն քարտի համար՝ լուսանկարներ, վիդեո, rich, բնութագրեր, նկարագրություն + վաճառք/օր։
3. **Միջազգային հետախուզում.** Amazon-ի «bought in past month» ցուցանիշով առաջատարները։ Այնտեղ այն տրենդերն են, որոնք WB-ին կհասնեն 6–18 ամսից։
4. **Աուդիտ ըստ սլայդների.**
   - Ինչ ցույց է տալիս 1-ին սլայդը (թիվ, մոդել, ֆոն)։
   - Սլայդների ստանդարտ հաջորդականությունը։
   - Լիդերների տեսողական կոդը։
   - **Ինչ ոչ ոք ցույց չի տալիս (բացը)։**
5. **Դիրքավորում.** մեկ նախադասություն. ուղղելի բողոքը + գնորդի արդյունքը։
6. **Բրիֆ.**
   - 10 սլայդ + վիդեո
   - rich 5–6 բլոկ (800×500 / 700×700 / 700×900)
   - վերնագիր ≤ 60 նիշ
   - բոլոր բնութագրերը
   - նկարագրություն բանալի բառերով
7. **Վիզուալներ.**
   - Լուսանկարները գեներացնում է Photo Editor-ը։
   - **Տեքստը սլայդի վրա գրում է մեր կոդը** (`compose`), ոչ թե AI-ը, որովհետև AI-ը աղավաղում է կիրիլիցան և թվերը։
8. **QA և առաքում.** յուրաքանչյուր կադր ստուգվում է ստորև նշված չեկլիստով։ Սխալ կադրը վերագեներացվում է։

## Իրավական կանոններ

- Մրցակիցների և Amazon-ի լուսանկարները օգտագործվում են **միայն վերլուծության համար**։ Չենք պատճենում և չենք հրապարակում։
- Մատակարարի լուսանկարները՝ միայն **կոնցեպտների** համար, «КОНЦЕПТ» նշումով։
- Հրապարակվում են միայն **մեր նմուշի** կադրերը (լուսանկար + գեներացիա դրա հիման վրա)։

## Հայտնի սահմանափակումներ (2026-10-20)

- Photo Editor-ում `infographics` ռեժիմը վերադարձնում է «request failed»։ `freeform`-ը և `photoshoot`-ը աշխատում են։ Տեքստային սլայդները պատրաստում ենք `compose`-ով։
- Մեծ base64 նկարները ընկնում են։ `gen`-ը ավտոմատ կրճատում է մինչև 1200 px։
