# Ինչպես են ապրանք ընտրում միջազգային պրակտիկայում (2026-10-18)

Գործիքներ՝ Exa `web_search_exa` (8 որոնում)։ Bright Data, MPStats, WB API՝ 0 հարցում։ Աղբյուրները նշված են ամեն պնդման կողքին (ամսաթվով, եթե կա)։
Թարգմանությունները անգլերենից, չինարենից և ռուսերենից իմն են։

## 1. Գլխավոր եզրահանգումը

1. Պրոֆեսիոնալները ընտրում են **4 առանցքով**՝ պահանջարկ (վաճառք/որոնում) → մրցակցության «պատ» (կարծիքների քանակը top-10-ում) → մարժա բոլոր ծախսերից հետո → տարբերակում (բողոքները կարծիքներում)։
2. Amazon-ի «ստանդարտը» սկսնակի համար. **գին $20–60, top-10-ում մի քանի քարտ < 300–500 կարծիքով, ≥ 30 % համախառն մարժա (≥ 20 % զուտ), < 2 ֆունտ, ամբողջ տարի, առանց բրենդի գերիշխանության**։
3. Չինական մոդելը ավելի «արագ» է. սոցցանցի ազդանշան (Douyin/Xiaohongshu) → 1688-ում գնորդների աճ → թեստ 20 նմուշով → 48 ժամում որոշում ըստ փոխարկման։
4. Թրենդը ԱՄՆ/Չինաստանից ՌԴ է հասնում **1–6 ամսում**։ Կարճ թրենդները WB-ում ապրում են **2–4 ամիս**։ Եթե թրենդի մասին արդեն գրում է մամուլը, մտնելն ուշ է։
5. Սկսնակին խորհուրդ չեն տալիս փխրուն, մարտկոցով/hazmat, սերտիֆիկացիա պահանջող, սեզոնային, commodity (անդեմ, միայն գնով մրցող) և շատ էժան (< $15) ապրանքներ։ **Մեր ֆիլտրերը սրանք արդեն փակում են**, բացի գնի ստորին սահմանից։
6. Գործիքների գնահատումները մոտավոր են (Helium 10-ի ճշգրտությունը 74–79 % է), ուստի բոլորը պահանջում են ձեռքով կրկնակի ստուգում, ինչպես մեր ±10–20 % կանոնը։
7. AI-ագենտներով արդեն կան աշխատող դեպքեր (գիշերային սկաուտ Claude-ով, MCP Claude Code-ում), բայց **վերջնական որոշումը միշտ մարդն է կայացնում**։

### 3.6 AI-ագենտների պրակտիկա
- **AZ Global (ԱՄՆ).** Claude-ով գիշերային ագենտ։
  - Աղբյուրներ՝ TikTok, Amazon, AliExpress, Meta Ad Library, Google Trends։
  - Հաշվում է մատակարարի landed cost-ը և գնահատում թեկնածուներին ըստ պահանջարկի, մրցակցության ու մարժայի։ Shortlist-ը պատրաստ է ժամը 7:00-ին։
  - Արդյունքը. ≈ 3 ժամ ձեռքի աշխատանք մեկ գնորդի համար օրական։ **Վերջնական որոշումը մարդունն է** [just.engineer, ամսաթիվ չկա]։
- **Launch Fast MCP Claude Code-ում.** մեկ հարցումով՝ շուկայի գնահատական, հիմնաբառեր, Alibaba-ի մատակարարներ և ապրանքանիշի ստուգում, < 2 րոպեում [launchfastlegacyx.com, 2026-03-20; գործիքի վաճառողի հոդված]։
- **ChatGPT + Helium 10.** ագենտը գտել է «baby shower decoration» նիշան (9 000 որոնում, 7 վաճառող, ≤ 100 կարծիք) և չզբաղեցված հատված՝ աղջիկների համար [Helium 10 Podcast, 2026-03-24]։
- **Claude Code որպես վերլուծաբան.** ≈ 30 % օպերացիաներ ավտոմատացված [Build to Launch, 2026-02-13]։
- **Եզրակացություն.** մեր մոդելը (Claude + MCP + որոշումը մարդունն է) համընկնում է հրապարակված լավագույն դեպքերի հետ։ Արդյունքի թվային ապացույց (ROI) ոչ մի աղբյուր չի տալիս։

## 4. Ինչ ընդունել մեր հոսքում (միայն առաջարկ)

1. **«Կարծիքների պատի» ֆիլտր** `niche_nocargo`/gates-ում. top-10-ում ≥ 3 քարտ < 300 կարծիքով (Saleflow-ի `comments` դաշտ)։ Հիմա սա ստուգում ենք միայն անուղղակիորեն՝ նորեկներով։
2. **ROI ≥ 100 %** (շահույթ / գնում)՝ երկրորդ դարպաս մարժայի կողքին։ Մեր ցածր ¥-ով (731՝ ¥ 4 ≈ գնի 9 %) այն հեշտությամբ կանցնի, բայց կզտի թանկ ապրանքները (1301)։
3. **Մատակարարի ստուգման քայլ** CHECKLIST-ում՝ «查三代» + `回头率` ≥ 50 % + շուկայում ≥ 3 տարի։ Bright Data-ն արդեն տալիս է `回头率`։
4. **Թեստի շեմերը՝ մինչև թեստը.** 30 օրվա kill-criteria-ն (CTR, CR, վաճառքներ) ամրագրել CHECKLIST-ում **մինչև** գնումը, ինչպես Rework-ում։
5. **Թրենդի ազդանշան.** շաբաթական ստուգում Exa-ով/Apify-ով՝ «Douyin/TikTok/Amazon Movers → WB» 1–6 ամսվա լագով։ Թրենդային ապրանքը՝ միայն փոքր պարտիայով (կյանքը 2–4 ամիս է)։

## 5. Որտեղ մենք արդեն ավելի խիստ ենք

| Մեզ մոտ | Միջազգային պրակտիկայում |
|---|---|
| Կոնցենտրացիայի թվային շեմեր (top-10 ≤ 40 %, top-1 ≤ 25 %, ≥ 3 հաղթող-վաճառող) | հիմնականում «աչքով» կամ «2–3 լիդեր ≥ 70 %» |
| Նորեկների իրական հաջողությունը (նորեկի P50 հատ/օր, survivorship-ի հաշվառում) | կարծիքների քանակը որպես անուղղակի ցուցանիշ |
| Բողոքների քանակական վերլուծություն (թեմա ≥ 12 % բացասականներում) | «կարդալ 200–300 կարծիք»՝ առանց շեմի |
| YoY ըստ պիկ ամսի (ոչ թե MoM) | Google Trends-ում «աճում է» |
| Stress −15 % գնի և выкуп-ի համար | −10 % գին, +20 % PPC (1 աղբյուր) |
| Կարգո, комиссия, тарифы՝ WB API-ից (փաստը գերակա է ենթադրությունից) | FBA հաշվիչ |
| Տվյալների մաքրում (outliers, ±10–20 % սխալ) | «գնահատումները 74–79 %-ով ճշգրիտ են» |

Թույլ կողմեր. մեզ մոտ չկան կարծիքների «պատի» և ROI-ի ֆիլտրեր, և չենք օգտագործում սոցցանցերի թրենդ-ազդանշանները։
