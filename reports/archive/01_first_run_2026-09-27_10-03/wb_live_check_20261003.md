# WB Seller API — իրական ստուգում (2026-10-03)

Թոքենը տեղադրված է `.env`-ում, բոլոր հարցումները արված են **իրական** WB API-ին։

## 1. Թոքենի տիպը և իրավունքները

| | |
|---|---|
| Տիպ | **Base token** (`acc=1`) ← ոչ Personal |
| Իրավունքներ | Контент, Аналитика, Статистика, Продвижение, Вопросы и отзывы, Поставки |
| Ռեժիմ | 🔒 Только на чтение |
| Sandbox | ոչ |
| Ժամկետ | 2027-04-03 (182 օր) |

## 2. Ինչ աշխատեց և ինչ՝ ոչ

| Կատեգորիա | Արդյունք | Մեկնաբանություն |
|---|---|---|
| Тарифы | ✅ | `/api/v1/tariffs/box`, `/commission` — իրական թվեր ստացված |
| Контент | ✅ | предмет-ների որոնում աշխատում է |
| Статистика | ✅ | `/api/v1/supplier/orders` |
| Продвижение | ✅ | |
| Аналитика | ⏳ | v3 էնդփոյնթը հասանելի է, բայց **Base-թոքենի լիմիտը ~1 հարցում/ժամ** է |
| Поставки | ⚠️ | FBW մեթոդները Base-թոքենով 404 են. приёмка-ն վերցվում է `common-api`-ից |

## 3. Կոդի 3 սխալ, որոնք բացահայտվեցին իրական API-ով

1. **Воронка продаж v2 անջատված է** (09.12.2025)։
   `/api/v2/nm-report/detail` → 404 → տեղափոխվեց **`/api/analytics/v3/sales-funnel/products`**,
   նոր սխեմա՝ `selectedPeriod` / `nmIds` / cursor-pagination։
2. **Приёмка-ի ուղին** → `supplies-api/api/v1/acceptance/coefficients` Base-թոքենով 404 է;
   հիմա նախ փորձվում է `common-api/api/tariffs/v1/acceptance/coefficients` (ցանկացած կատեգորիա)։
3. **429-ի անվերջ սպասում** → ավելացվեց `max_wait=120վրկ` սահման՝ պարզ ուղերձով։
   Նաև՝ `_deep_merge`-ը ընկնում էր float-բանալիների վրա; `decode_token`-ը սխալ էր կարդում `.env`-ը։

## 5. Ինչ է սա նշանակում փողով

`config/tariffs_auto.yaml` արդեն գեներացված է **СЦ Ереван**-ի իրական թվերով.

| Ապրանք | Լոգիստիկա (ՌԴ ենթադր. → իրական) | Մարժա | Break-even |
|---|---|---|---|
| 1,490 ₽ / 0.5 լ | 78 → **164 ₽** | 25.3% → **19.4%** | 863 → **1,009 ₽** |
| 1,200 ₽ / 0.8 լ | 81 → **164 ₽** | 18.3% → **11.2%** | 833 → **976 ₽** |
| 2,200 ₽ / 0.9 լ | 85 → **164 ₽** | 23.0% → **19.3%** | 1,356 → **1,492 ₽** |

**Եզրակացություն.** Երևանից աշխատելիս լոգիստիկան **2× ավելի թանկ է**, քան ՌԴ-ի բազային
ենթադրությունը։ 1,200 ₽ գնի գոտին դառնում է վտանգավոր (11% մարժա)։
Նոր նվազագույն գին 20%+ մարժայի համար՝ **~1,400 ₽**, իսկ Ташкент-ի տարբերակով՝ ~1,150 ₽։
