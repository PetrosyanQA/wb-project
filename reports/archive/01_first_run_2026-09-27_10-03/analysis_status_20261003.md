## Ահա վերլուծությունը, որը հենց նոր արեցի

Նոր մոդուլ՝ `src/category_econ.py`։ Օգտագործում է **միայն քո սեփական WB API-ն**
(`/api/v1/tariffs/commission` → 7415 կատեգորիա, 95 ծնող-խումբ) + Երևանի իրական
տարիֆները + ներկրման մոդելը։

### Հարց. ¥15 գործարանային ապրանքի դեպքում ո՞րն է նվազագույն վաճառքի գինը ամեն կատեգորիայում

Մուտք՝ ¥15 · 0.35 կգ · 20×14×9 սմ · 300 հատ · բեռնատար → **ինքնարժեք 439 ₽**
Թիրախ՝ մարժա ≥18% ԵՎ ROI ≥60% · СЦ Ереван · FBW

| Կատեգորիա | Комиссия % | Մին. գին | ×¥ |
|---|---:|---:|---:|
| Транспортные средства / Автомобили | 0.5 | **1181 ₽** | 6.8 |
| Фарма | 3.0 | 1219 ₽ | 7.1 |
| Продукты · Алкогольная продукция | 4.5 | 1242 ₽ | 7.2 |
| Товары для животных · Ветаптека | 11.5 | 1366 ₽ | 7.9 |

| Бытовая техника · Умный дом | 15.5 | 1448 ₽ | 8.4 |
| … | … | … | … |
| Обувь · Белье для малышей · Спортивная обувь | 24.5 | **1686 ₽** | 9.8 |

### 🔑 Հիմնական եզրակացությունը — անսպասելի

**Կատեգորիայի ընտրությունը էկոնոմիկապես գրեթե նշանակություն չունի։**

Կոմիսիան տատանվում է 0.5%-ից 24.5% — 49 անգամ տարբերություն — բայց դա
նվազագույն գինը փոխում է ընդամենը **1181 → 1686 ₽**, այսինքն ~500 ₽։
**Բոլոր 95 կատեգորիաները** տեղավորվում են ≤2600 ₽ գոտում։

Իրական սահմանափակողները այլ են.

| Գործոն | Ազդեցություն |
|---|---|
| **Ներկրման հավելում** | ×2.3 գործարանի ¥ գնից (¥15 → 439 ₽) |
| **Երևանի լոգիստիկա** | 164 ₽/միավոր — ՌԴ-ից **2×** թանկ |
| WB կոմիսիա | ~500 ₽ տարբերություն լավագույն և վատագույն կատեգորիայի միջև |

Այսինքն՝ **պետք է վաճառել ×7–10 գործարանի ¥ գնից**, անկախ կատեգորիայից։
Ապրանքի ընտրությունը պետք է հենվի **պահանջարկի և մրցակցության** վրա, ոչ թե կոմիսիայի։

### Գործնական հետևանք որոնման համար

- ¥8–25 գործարանում → վաճառել **1500–2600 ₽** (հաստատվում է անկախ ճանապարհով)
- Կոմիսիայի պատճառով կատեգորիա մի՛ ընտրիր — տարբերությունը աննշան է
- Խուսափիր միայն 24.5%-անոց խմբերից, եթե գինը սեղմված է 1500 ₽-ի մոտ
- Քաշը/ծավալը **ավելի կարևոր են**, քան կատեգորիան. ծավալային քաշը պատժում է
  թեթև-մեծածավալ ապրանքը (0.35 կգ → վճարում ես 0.42 կգ-ի համար)

### Վերարտադրում

```bash
python3 -m src.category_econ --cny 15 --volume 0.5           # мин. գին ըստ կատեգորիայի
python3 -m src.category_econ --price 1900 --volume 0.5       # макс ¥ ըստ կատեգորիայի
python3 -m src.category_econ --cny 15 --parent "Дом"         # ֆիլտր ծնողով
python3 -m src.category_econ --cny 15 --model fbs            # FBS կոմիսիաներով
```

Լրիվ աղյուսակները՝ `reports/category_minprice_cny15.md`, `reports/category_econ_1900.md`։
