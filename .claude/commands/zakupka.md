# Закупка (поставщик → образцы → партия)

Запрос пользователя: **$ARGUMENTS** (по умолчанию — товар из `PROJECT_STATE.md`).

## Что делает (простыми словами)
Доводит выбранный товар до оплаты партии без сюрпризов: готовит запрос поставщику, проверяет его ответ, считает точную
себестоимость «под ключ», планирует образцы и тест качества, проверяет документы и решает, **сколько штук брать**.
Партию оплачиваем только когда пройдены **3 условия**: цена «под ключ», тест образцов, реальная СПП на нашей карточке.

## Как запустить
- `/zakupka` — для текущего товара.
- `/zakupka пришло КП, файл docs/suppliers/...` — разобрать ответ поставщика.

## Шаги
| # | Шаг | Чем |
|---|---|---|
| 1 | **Запрос КП** (текст на русском/английском/китайском): цена за штуку на 2–3 объёма партии, **код ТН ВЭД**, ставка НДС и пошлины, вес и размер короба, срок, условия «под ключ» до склада | черновик в чат → **отправляет только пользователь** после проверки текста |
| 2 | **Разбор КП**: все платежи (товар, агент, банк, доставка, таможня, пошлина, НДС, страховка, фикс) → цена «под ключ» за единицу; несоответствия (материал ≠ код ТН ВЭД, НДС ≠ 22 %) — вопросами поставщику | `docs/suppliers/`, пример разбора `yuanexim_offer_2026-10-22.md` |
| 3 | **Пересчёт экономики** по КП (не по целевой цене) | `src/unit_econ.py`, `python -m src.budget_sim` |
| 4 | **Образцы**: 3–5 шт на наш FBS-склад; тест (для лент: груз ×2, 100 растяжений на шов, −18 °C) с фото/видео | чек-лист в отчёте |
| 5 | **Документы**: «Честный знак» по коду ТН ВЭД, декларация/отказное письмо, маркировка EAC, кто оформляет ГТД | Exa (поиск в вебе), `docs/wb_help/` |
| 6 | **Размер партии**: деньги на товар + реклама 3 месяцев + резерв; дни без товара по `budget_sim` ≤ 30 за полгода | `python -m src.budget_sim` |
| 7 | **3 условия до оплаты** (из премортема): цена «под ключ» ≤ порога; тест образцов без брака; СПП на нашей карточке в нужной полосе | `reports/premortem_*.md` |

## Что получите
Таблица «под ключ» (было → стало), решение по партии (сколько штук, сколько денег на что), статус 3 условий ✅ / ⚠️,
готовый текст письма поставщику. Конец — «Следующий шаг».

## Что можно поменять
| Что | Где |
|---|---|
| Порог цены «под ключ», маржа | `config/unit_economics.yaml`, решение в `reports/decision_*.md` |
| Курс, НДС, пошлина, фикс таможни | `config/landed_cost.yaml` |
| Бюджет и доли | `config/scoring.yaml` |

## Правила
Письма поставщикам и любые платежи — **только после «да» пользователя**. Ключи и пароли в письма не вставлять.
