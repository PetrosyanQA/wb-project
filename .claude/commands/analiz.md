# Анализ товара — главный порядок (версия 2026-11-02, после аудита)

Запрос пользователя: **$ARGUMENTS**. Если пусто — анализ текущего товара из `PROJECT_STATE.md`.

## Как читать этот файл
6 этапов. На каждом есть **ворота**: прошёл → следующий этап; не прошёл → **стоп** и честный ответ «почему нет» (подгонять нельзя).
У каждого шага указано: чем считать, сколько стоит, где правда. Цифра без источника → «—» и причина.
Ответ — по-русски, полностью в чат, копия — в `reports/analiz_<товар>_<дата>.md`.

## Режим запуска (выбрать сам по запросу)
| Запрос | Режим | Этапы |
|---|---|---|
| «сделай анализ» / «проверь наш товар» | **Проверка текущего** (кисти 437) | 0 → 2 → 3 → 4 → 5 → 6 (этап 1 пропустить) |
| «проверь товар X» | **Проверка названного** | 0 → 1 (только уникальность X) → 2 → 6 |
| «ищем новый товар» (прямо) | **Поиск** | 0 → 6 полностью |
| любой запрос, пока действует стоп-решение | — | новый товар **не искать**; идею записать в `docs/kopilka.md` |

## Этап 1. Уникальность (сначала зарубеж, потом WB)
Урок 01.11: «пробел» по названиям в топ-500 оказался ложным; комплект с эспандером есть на Amazon, но не продаётся.
| # | Что | Чем | Стоимость | Ворота |
|---|---|---|---|---|
| 1.1 | Что **продаётся** за рубежом: ASIN с «куплено за месяц» ≥ 100 или ≥ 500 отзывов; лучше растущие новинки (≥ 1 000/мес при < 500 отзывах) | Bright Data `fetch` Amazon (разбор `global_variants.parse`), Apify TikTok Shop | 1 кредит / запрос; 0,1–0,5 USD | есть ASIN с продажами → дать ссылку `amazon.com/dp/<ASIN>` |
| 1.2 | Есть ли это на WB — **живая выдача**, только органика (`promoted == false`), 2–4 русские формулировки | Saleflow `wb_check_rates` | 1 запрос на формулировку | < 5 точных аналогов с > 200 отзывами **И есть спрос на WB**: если карточек много, а продаж ≈ 0 — у покупателя WB спроса нет (стоп) |
| 1.3 | Соседние предметы WB (корректор → «Корсеты ортопедические») — тоже проверить | `wb_check_rates` по синонимам | 1–2 запроса | в соседнем предмете тоже нет гигантов |

## Этап 6. Ответ пользователю (шаблон)
1. **Вывод одной фразой**: продаём / не продаём / нужна проверка X.

4. **Экономика**: таблица СПП 18 / 10 / 0 % × тестовая / основная партия; прибыль/шт и в месяц.
5. **Жалоба, которую исправляем**, и состав товара.

8. **Проверка анализа** (чек-лист).

Под каждой таблицей — период данных; октябрь 2026 — с пометкой «неполные».
