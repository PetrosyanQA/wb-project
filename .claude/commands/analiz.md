# Анализ (версия 1.0, 2026-11-02)

Запрос пользователя: **$ARGUMENTS** (пусто — текущий товар из `config/decision_current.yaml`).
Ответ — по-русски, полностью в чат; копия — `reports/dossier_<ниша>_<дата>.md`. Цифра без источника → «—» и причина.

## Режимы (выбрать по запросу) — бюджет на прогон из `config/project.yaml → budgets.modes`
| Запрос | Режим | Что делаем |
|---|---|---|
| «сделай анализ», «проверь наш товар» | Проверка текущего | шаги 0, 2–5 по текущей нише |
| «усиль / уникальность нашего товара» | Усилить текущий | 0, 1 (фишки и комплекты для нашей ниши), 2–5 |
| «проверь товар X» | Проверка идеи | 0, 1, 2–5 по нише X |
| «ищем новый товар» | Поиск | 0, `src.wb screen` → `src.wb analyze --top 10` → 1–5 по 3 лучшим |
Режим проекта `FROZEN_TEST` → новые идеи только в `docs/kopilka.md`. Цикл поиска кончается `discovery_until` — тогда только решение.

## Шаги
**0. Подготовка (0 ₽).**
`python -m src.wb status` (источники, лимиты, свежесть) и `python -m src.wb decide` (режим, срок цикла).
Прочитать `learning/LESSONS.md`. Записать в отчёт 2–3 «убивающих» допущения; пороги — только из `config/project.yaml`
(внутри цикла не менять). Назвать инструменты шагов и расход до платных вызовов (таблица «Выбор инструмента» в `CLAUDE.md`).

**1. Спрос и фишки за рубежом (Exa, бесплатно).**
4–6 запросов Exa (TokConnect, FastMoss, asinsight/AMZScout, Etsy, Kickstarter, vc.ru/RWB): только товары с цифрами (шт, выручка, рост),
сторонние оценки — с меткой «оценка», для решения ≥ 2 источника. Отсеять магниты, > 1 л, сезонный всплеск, бренды/лицензии.
Записать `data/raw/exa/<дата>/abroad_<ниша>.md` — строки с цифрами и ссылками (досье засчитывает спрос за рубежом только по этому файлу).

**2. Досье — все источники одной командой.**
`python -m src.wb analyze <ниша> --query "<формулировка>" [--query "<ещё>"] --yuan-kw "<слова 1688 через запятую>" [--offer <id>] [--complaints]`
Блоки: паспорт (все ниши) · сегменты/новички/монополия · типы внутри · структура рынка, динамика, сезон, живая выдача (Saleflow) ·
жалобы · спрос за рубежом · ¥ 1688 · карточки WB (габариты, ЧЗ, магнит) · комиссия кабинета · СПП · экономика СПП 18/10/0 × ¥ и ¥×1,3 ×
партия 100/300 × ДРР 8/15 · Монте-Карло · ворота и решение · сравнение с планкой (тот же расчёт).

**3. Закрыть пробелы досье** (раздел «Недоступно / не запущено»):
нет ¥ нужной комплектации → `python -m src.brightdata_client s1688 "<китайский запрос>" --name <ниша>` (1 кредит) или `--offer`;
нет жалоб → `--complaints`; Saleflow 401 → сказать пользователю перевыпустить токен; блоки 4–7 без токена — вывод «предварительный».
После правок — досье заново.

**4. Решение — только из досье** (`src.decision`, ворота: спрос WB и за рубежом, уникальность, поставщик, экономика, документы).
ESTIMATE → максимум WATCHLIST; нет образца → нельзя SOURCE; нет тестовых продаж → нельзя SCALE.
Главное неизвестное, которое анализом не измерить (СПП нашего кабинета, конверсия, выкуп) → тестовая партия 50–100, а не новый анализ.
Выбор между нишами — по прибыли новичка в месяц и риску, не по % маржи. Для текущего товара — обновить `config/decision_current.yaml`.

**5. Ответ (шаблон) + обучение.**
1) Решение go/no-go одной фразой с датой («перспективно» — не решение). 2) Уникальность: зарубеж (ссылки, цифры) + живая выдача WB.
3) Ворота ✅/❌ с цифрами и источниками. 4) Экономика СПП 18/10/0 и риск. 5) Жалоба, которую исправляем, и состав товара.
6) Топ-3 риска и как проверить на образце. 7) Kill-критерии (`config/launch.yaml`). 8) Чек-лист `docs/ANALYSIS_CHECKLIST.md` и «что не проверено».
9) Инструменты и расход против бюджета режима. 10) Следующий шаг — одно действие.
Обучение: `python -m src.learning predict` (СПП, ¥, продажи новичка — минимум 3); новая ошибка → `learning lesson`; пришёл факт → `learning fact`.

## Правила
Запрет — только магниты (ЧЗ, документы, электроника — «оформить»). Данные продаж старше 30 дней → «предварительно».
Хит за рубежом без спроса на WB — не кандидат. Кросс-бордер карточки — не аналог и не доказательство «нет спроса».
¥ из выдачи 1688 — цена позиции, не набора: для решения — карточка оффера или КП. Деньги, письма, цены, публикации — только после «да».

## 10 главных уроков (полный список — `learning/LESSONS.md`)
«Пробел» по названиям ≠ пустая ниша (живая выдача) · хит Amazon/TikTok часто без спроса на WB · кросс-бордер искажает выдачу ·
лучшая уникальность — фишка для своей ниши · медиана всей ниши хоронит премиум (смотреть сегменты) · ¥ из поиска 1688 ≠ цена набора ·
оценка ¥ = 11 % цены для электроники ошибочна (принтеры, геймпады) · Saleflow — цены покупателя после СПП, маржа по цене продавца ·
комиссия и тарифы — только из кабинета · товар менялся 10+ раз без образца → стоп-решение и тестовая партия.
