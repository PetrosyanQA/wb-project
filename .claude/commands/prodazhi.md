# Запуск и продажи (управление после появления карточки)

Запрос пользователя: **$ARGUMENTS** (например: «отчёт за неделю», «реклама», «цена», «отзывы»).

## Что делает (простыми словами)
Ведёт товар после старта: держит цену в нужной полосе СПП, ведёт рекламу в рамках ДРР, отвечает на отзывы (черновики),
следит за остатками, сравнивает план с реальностью и вовремя говорит «стоп» по kill-критериям.
**Любое изменение в кабинете WB (цена, реклама, ответы, карточка) — только после «да» пользователя.**

## Как запустить
- `/prodazhi` — сводка и 3 действия на неделю.
- `/prodazhi реклама` / `цена` / `отзывы` / `остатки` — один блок подробно.

## Что нужно
Ключ WB с правами (Контент, Цены, Статистика, Аналитика, Продвижение, Вопросы и отзывы, Маркетплейс, Финансы) —
пользователь кладёт его сам в `.env` (`WB_TOKEN_PERSONAL=…`) и в GitHub Secrets для облака. Проверка прав: `python -m src.wb_seller decode`.

## Блоки
| Блок | Что смотрим | Чем |
|---|---|---|
| **Цена и СПП** | граница полосы, наша СПП, цена для покупателя ≤ потолка | отчёт `src/brush_report.py` + `config/watch_437.yaml` (Telegram 10:00); `cloud_daily` — старый (249), выключен, `python -m src.evirma show <id>` |
| **Реклама** | расход, ДРР, стоимость заказа против точки нуля; на запуске — потолок ДРР и дневной бюджет | API Продвижения (бит 6) |
| **Отзывы и вопросы** | новые отзывы, темы негатива («порвалась», «не та нагрузка»), черновики ответов | API Вопросы и отзывы (бит 7) |
| **Остатки и заказы FBS** | остаток в днях продаж, срок сборки 48 ч, когда дозаказывать (учесть 45 дней доставки) | `python -m src.wb_facts`, API Маркетплейс |
| **План против факта** | выкуп, воронка, реальные выплаты против `unit_econ`; расхождение > 5 % → заменить допущение фактом | `python -m src.wb_facts buyout/funnel/regions --days 30`, финотчёт |
| **Kill-критерии** | из решения: стоимость заказа, ДРР, выкуп, жалобы на брак, заказы на 30/60-й день | `config/launch.yaml → kill_rules` (кисти 437, единые) |
| **Конкуренты** | цены, реклама, остатки, новые карточки в топе | `src/competitor_pulse.py`, Saleflow |

## Что получите
Сводка ✅ / ⚠️ / ❌ по блокам, что изменилось за период, и **не больше 3 действий** на неделю по влиянию на деньги
(каждое — «сделать?» → ждём «да»).

## Что можно поменять
| Что | Где |
|---|---|
| Товары и пороги облачной проверки (цена, СПП, запасной товар) | `config/cloud.yaml` |
| Цены, kill-правила (единые) | `config/launch.yaml`; конкуренты — `config/watch_437.yaml` |
| Время отчёта в Telegram | `.github/workflows/daily.yml` (`cron`) |
