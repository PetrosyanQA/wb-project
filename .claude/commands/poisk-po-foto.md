# Поиск товара по описанию и по картинке

Запрос пользователя: **$ARGUMENTS** — описание («сумка тоут А4 экокожа молния»), ключ ТЗ (`tote`), артикул WB или ссылка на фото.

## Что делает (простыми словами)
**Пользователь фото не присылает.** Скилл сам находит картинки товара по описанию — в Китае, на международных площадках
и в Pinterest:
1. собирает из них лист с номерами;
2. Claude смотрит лист и выбирает картинки, похожие на наш товар;
3. по каждой выбранной картинке ищет **ту же модель**: на каких сайтах и маркетплейсах она продаётся, по какой цене,
   есть ли она на 1688 / AliExpress (фабрика), сколько продавцов у неё уже на WB / Ozon.

## Как запустить
- `/poisk-po-foto tote` — по готовому ТЗ (ключ в `SPECS` в `src/photo_hunt.py`).
- `/poisk-po-foto сумка тоут А4 экокожа молния` — новое описание. Claude добавляет ключ в `SPECS`:
  - `ru`, `en` — запросы;
  - `cn_files` — запросы 1688 из `src/spec_find.py`;
  - `plus` / `minus` / `keep` — слова для оценки картинок.
- `/poisk-po-foto 949363603` — по артикулу WB (сразу шаг 6).

## Шаги
| # | Шаг | Чем | Стоимость |
|---|---|---|---|
| 1 | **Описание → запросы** RU / EN / CN + слова «плюс» (совпадает с ТЗ) и «минус» (магнит, ткань, детское, принт…) | `SPECS` в `src/photo_hunt.py` (+ китайские в `src/spec_find.py`) | 0 |
| 2 | **Яндекс Картинки по тексту × площадки**: Pinterest, AliExpress, WB, Ozon, Я.Маркет, весь интернет (RU и EN) — картинка, подпись, страница | `python -m src.photo_hunt yandex --spec <ключ>` (без браузера; при капче — стоп и встроенный браузер вручную) | 0 |
| 3 | **1688 и Amazon**: офферы 1688 с фото, ценой ¥ и id (выдачи `spec_find`), поиск Amazon (фото, ASIN, $) | `python -m src.spec_find search --spec <ключ>` → `python -m src.photo_hunt collect --spec <ключ>` | 1 кредит Bright Data на запрос |
| 4 | **Лист для выбора**: скачать картинки, баллы по описанию, листы 6×5 с номерами, площадкой и ценой | `python -m src.photo_hunt sheet --spec <ключ>` → открыть `data/raw/photo_hunt/<ключ>/sheet_N.jpg` (Read) | 0 |
| 5 | **Выбор глазами**: Claude смотрит листы и выбирает 3–6 картинок ближе всего к ТЗ. Пример для сумки: классический тоут, молния, жёсткая форма, косметичка, чёрный/шоколадный. Номера + почему — в чат | Read листов | 0 |
| 6 | **Та же модель по картинке**: Яндекс «Сайты» для каждой выбранной → где продаётся, цены, артикулы WB / Ozon, AliExpress / 1688 / Alibaba / DHgate; только совпадения того же типа товара (`keep`) | `python -m src.photo_hunt pick --spec <ключ> <номера>` → `reports/image_find_<ключ>_<n>_<дата>.md`; по артикулу WB — `python -m src.image_find auto <артикул> --photo N --name <имя>` | 0 |
| 7 | **Вывод** | отчёт + полный текст в чат | 0 |

Как читать вывод (шаг 7):
- модель есть на 1688 / Alibaba → фабрика найдена, ссылка в `/zakupka`;
- модель уже у многих продавцов WB / Ozon дешевле нашей цены → не берём как есть, нужна доработка или своя модель;
- модель уникальная (0–2 совпадения, например только Я.Маркет) → место есть, но фабрику искать через `spec_find` по описанию.

## Что получите
1. Листы картинок со всех площадок с номерами и ценами.
2. 3–6 выбранных моделей с причиной выбора.
3. По каждой: где продаётся та же модель, цены, ссылки, фабрика (если найдена) и вывод — брать, дорабатывать или нет.

## Ограничения (проверено 27.10.2026)
- **Простые модели** (однотонный чёрный тоут) похожи друг на друга. Поиск по картинке выдаёт похожие, а не точные копии,
  и в выдаче много брендов (Burberry, Coach). Точные совпадения находятся для **узнаваемых** моделей:
  - #50 Kenguluna — только Я.Маркет и 100sp;
  - эталон 1688 ¥42 — его продают в России через «Фабрику сумок BAGS».
- Bright Data не пускает на Pinterest / AliExpress напрямую (robots.txt) — берём их через Яндекс Картинки, не обходим.
- Поиск 1688 по картинке требует загрузки файла — для фабрик используем `src/spec_find.py` (по описанию) и совпадения 1688 / Alibaba из шага 6.
- Картинки площадок — только для анализа, в нашу карточку не идут.
