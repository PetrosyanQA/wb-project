# Выбор товара (анализ ниш + выбор товара + проверка)

Запрос пользователя: **$ARGUMENTS**

## Что делает (простыми словами)
Проходит весь путь от «товара нет» до «вот что покупаем и почему»: смотрит все ниши WB, отбрасывает запрещённые и невыгодные,
выбирает лучшие, проверяет СПП, ищет конкретный товар, разбирает конкурентов и их отзывы, считает деньги и выдаёт
**1 товар + 2 запасных** с планом на бюджет.
Если пользователь назвал товар или нишу — шаги 1–3 пропускаются, сразу идёт **проверка** этого товара (шаги 4–10).

## Как запустить
- `/vybor-tovara` — искать с нуля.
- `/vybor-tovara лента для подтягивания 249` — проверить конкретный товар.
- `/vybor-tovara только товары для дома, до 3000 ₽` — искать с ограничениями.

## Правила пользователя (не нарушать)
Из `CLAUDE.md` и памяти: бюджет **$2 000**; армянский кабинет, схема **FBS**; закупка **только белым импортом YUAN EXIM**;
маржа считается по **цене продавца** (до СПП); налог 10 %; **нельзя**: «Честный знак», магниты, батареи, электроника;
декларации — не проблема; выбор — по **общей прибыли** (прибыль/шт × реальные продажи, оборот денег), а не по проценту маржи.

## Шаги (сначала бесплатное, потом платное)
| # | Шаг | Чем | Стоимость |
|---|---|---|---|
| 1 | **Все ниши → убрать запрещённое**: ЧЗ (по коду ТН ВЭД), электроника, батареи, магниты, громоздкое, жидкости | `data/processed/niche_requirements_*.json`; обновить: `python -m src.niche_requirements` | 0 |
| 2 | **Деньги в нише**: выручка, медиана цены, число продавцов; цена покупателя должна выдерживать белый импорт (лёгкий товар, обычно ≥ 1 000–1 500 ₽) | тот же файл, `config/scoring.yaml` | 0 |
| 3 | **Спрос и его рост**: поисковые запросы, рост год к году ≥ ×2 (база ≥ 1 000), сезон | `python -m src.seo_gap analyze`, `python -m src.seo_gap growth`; новые ниши — `seo_gap collect` | 1 запрос Saleflow на нишу |
| 4 | **Рынок ниши**: концентрация (один продавец ≤ 25 %, в т.ч. в точном подтипе), новички P25/P50 по месяцам, ценовые сегменты | `python -m src.strategy_collect --niche <id> --step core` (топ-500 за последний **полный** месяц ≤ 07.2026) | ~5–10 запросов |
| 5 | **Конкуренция в выдаче — только без рекламы** (`promoted == false`). Реклама наверху ≠ свободное место | Saleflow `wb_check_rates` | 1 запрос на запрос |
| 6 | **СПП**: какая скидка WB будет у нашей цены продавца; минимум 2 замера в разные дни | `python -m src.evirma show <id>` (поле `spp` полосы) | 0 |
| 7 | **Конкретный товар и конкуренты**: 5 карточек точного типа (2 лидера, 1 середина, 2 новичка), их цены, продажи, реклама, остатки, что входит в комплект | Saleflow `wb_sku by_period`, карточки WB `src.wb_cdn_card` | 2 запроса на карточку |
| 8 | **Жалобы покупателей** по точному типу → одна исправимая жалоба = наше преимущество | `src.niche_monitor.feedbacks` (отзывы WB) | 0 |
| 9 | **Экономика**: реальная цена в Китае (КП, 1688, Yiwugo), вес, короб, комиссия из WB API → прибыль/шт; деньги за 6 мес по сценариям | `src/unit_econ.py`, `python -m src.wb_seller commission --subject "<предмет>"`, `python -m src.budget_sim` | 0 |
| 10 | **Проверка анализа + премортем**: 15 ловушек данных и «через 6 мес провалились — почему?» | `docs/ANALYSIS_CHECKLIST.md` | 0 |

Перед шагами 3–5 сообщи остаток лимита Saleflow (500 в день); при остатке < 50 — предупреди и спроси.

## Что получите
1. **1 товар + 2 запасных**, по каждому: метрики ниши с периодом, почему он лучше по общей прибыли,
   таблица экономики, план партии на $2 000, топ-3 риска, kill-критерии на 30-й день, жалоба, которую исправляем.
2. Блок **«Проверка анализа»** — 15 пунктов ✅ / ⚠️.
3. **«Следующий шаг»** — одно действие (обычно: `/zakupka`).
Все цифры с метками [факт] / [оценка] / [допущение]; полный текст — в чате, копия — `reports/vybor_tovara_<дата>.md`.

## Что можно поменять (настройки)
| Что | Где |
|---|---|
| Бюджет, курс, доля на товар/рекламу/резерв | `config/scoring.yaml` → `budget` |
| Коридор цены, минимальная выручка ниши | `config/scoring.yaml` → `constraints` |
| Порог маржи (18 %) и окупаемости (60 %), выкуп, ДРР | `config/unit_economics.yaml` |
| Схема кабинета (FBS, ФФ 30 ₽, налог) | `config/scheme_am_fbs.yaml` |
| Формула белого импорта | `config/landed_cost.yaml`, `docs/suppliers/` |
| Список ловушек анализа | `docs/ANALYSIS_CHECKLIST.md` |

## Честно: чего пока нет
- Продажи Saleflow после июля 2026 неполные — свежий месяц по продажам недоступен.
- Число товаров в выдаче WB по запросу напрямую не измерить (публичный поиск закрыт), только по топ-100.
- Реальную СПП нашего кабинета покажет только живая карточка (см. `/zakupka`, образцы).
