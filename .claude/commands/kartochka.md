# Карточка товара (что видит покупатель)

Запрос пользователя: **$ARGUMENTS** (ниша и товар, например `249 набор лент 22+32 мм`).

## Что делает (простыми словами)
Делает карточку, которая продаёт: смотрит, как оформлены лидеры на WB и Amazon, находит, чего у них нет, формулирует
одно главное обещание (исправленная жалоба + результат для покупателя), пишет название и описание с ключевыми словами,
заполняет характеристики, готовит 10 слайдов галереи, видео и rich-блоки. Подробности — `marketing/README.md`.

## Как запустить
- `/kartochka` — для текущего товара из `PROJECT_STATE.md`.
- `/kartochka 249 набор лент 22+32 мм` — для указанного.

## Шаги
| # | Шаг | Чем | Стоимость |
|---|---|---|---|
| 1 | **Данные**: топ-500 ниши, жалобы покупателей, ключевые слова | `src.datastore`, `src.strategy_collect --step core`, отзывы WB | Saleflow при отсутствии данных |
| 2 | **Маркетинговый разбор**: SEO-ядро, жалобы → УТП, доля рекламы, реклама конкурентов, СПП, бюджет рекламы | `python -m src.mkt_analyze --niche <id>` | 0 |
| 3 | **Галереи лидеров WB** | `python -m src.mkt wb --niche <id> --top 12` | 0 |
| 4 | **Галереи Amazon** (идеи подачи) | `python -m src.mkt amazon --niche <id> --query "<english>" --detail 6` | ≈ 7 кредитов Bright Data (стоп при < 100) |
| 5 | **Аудит**: что показывают лидеры слайд за слайдом, какие цифры на первом слайде, **чего не показывает никто** | `python -m src.mkt audit --niche <id>` + просмотр картинок | 0 |
| 6 | **Позиционирование**: одна фраза = исправленная жалоба + результат. Никаких обещаний, которые товар не докажет | — | 0 |
| 7 | **Текст**: название ≤ 60 знаков, описание с ключами из поиска, все характеристики | `src/wb_card.py` (заполнение по API — только после «да») | 0 |
| 8 | **Визуал**: фото — Photo Editor (`python -m src.mkt gen`), слайды с текстом — кодом (`python -m src.mkt compose`), не нейросетью (она путает кириллицу). Каждый кадр проверить: товар тот же, применение правильное, читается с телефона | Saleflow Photo Editor | по запросам |
| 9 | **Чек-лист продающей карточки** (идея из coreyhaines31/marketingskills, CRO): первый слайд отвечает «что это и чем лучше» за 2 секунды; размерная таблица «вес → лента»; доказательство (видео теста); ответы на 3 главных возражения из отзывов; без «латекса», если товар TPE | — | 0 |

## Что получите
`marketing/<id>/brief_<дата>.md` + готовые слайды; полный текст брифа — в чате, картинки — файлами. Конец — «Следующий шаг».

## Что можно поменять
| Что | Где |
|---|---|
| Правила WB по фото (размеры, плашки) | `docs/wb_help/` |
| Шаблоны слайдов | `marketing/<id>/slides/*.json` |
| Кредиты Bright Data (стоп при < 100) | память проекта |

## Правила
Фото поставщика/конкурентов — только как «КОНЦЕПТ»; в карточку идёт **наш** образец. Загрузка в кабинет WB — только после «да».
