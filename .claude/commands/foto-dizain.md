# Фото и дизайн карточки (исследование → бриф → Canva)

Запрос пользователя: **$ARGUMENTS** (ниша и товар; по умолчанию — товар из `PROJECT_STATE.md`).

## Что делает (простыми словами)
Сначала смотрит, **как продают конкуренты**: собирает список лидеров и новичков нашего типа товара, скачивает их галереи
с WB и лучшие карточки Amazon, раскладывает на листы и разбирает каждый слайд. Из этого делает **бриф** — что показать
на каждом из 10 слайдов и чем мы отличаемся. Потом **генерирует дизайн в Canva**, проверяет каждый кадр и отдаёт файлы.
Без анализа дизайн не делаем.

## Как запустить
- `/foto-dizain` — весь процесс для текущего товара.
- `/foto-dizain 249 набор лент TPE` — для указанного товара.
- `/foto-dizain только анализ` — шаги 1–6 без дизайна. `/foto-dizain только дизайн` — если анализ уже есть.

## Шаги
| # | Шаг | Чем | Стоимость |
|---|---|---|---|
| 1 | **Список конкурентов**: 15–20 карточек нашего типа и цены — лидеры по выручке + новички за год; исключить другие типы | `python -m src.gallery_research list --niche <id> --price <от> <до> --include "<слова>" --exclude "<слова>" --top 18` → проверить список глазами | 0 |
| 2 | **Галереи WB** (фото, rich, видео) | `python -m src.gallery_research fetch --niche <id>` | 0 (CDN WB) |
| 3 | **Карточки Amazon** по английскому запросу товара | `python -m src.gallery_research amazon --niche <id> --query "<english>" --detail 8` | ≈ 9 кредитов Bright Data (стоп при < 100) |
| 4 | **Листы-сравнения**: 1 строка = 1 карточка | `python -m src.gallery_research sheets --niche <id>` → открыть `marketing/<id>/research/*.jpg` | 0 |
| 5 | **Разбор**: таблица конкурентов (цена, продажи, отзывы, комплект, стиль); сколько карточек показывают каждый тип слайда; что делает Amazon; чего не показывает никто; **что это значит для самого товара** (комплект, цена) | отчёт `marketing/<id>/research/analysis_<дата>.md` (образец — 249) | 0 |
| 6 | **Бриф 10 слайдов**: тип слайда, главная фраза, цифры (только [факт] или «по данным производителя»), картинка, откуда идея (WB-стандарт / Amazon / наш пробел) + стиль, чтобы отличаться | в том же отчёте | 0 |
| 7 | **Картинки товара**: фото образца или того же артикула у поставщика → убрать фон; фото «в деле» — нейросеть (режим `freeform`) | `python -m src.mkt gen --mode remove-bg / freeform` | по тарифу Saleflow |
| 8 | **Дизайн в Canva**: дизайн 900×1200 (3:4), 10 страниц по брифу; вырезанные фото товара — загрузить как ассеты; тексты — из брифа; экспорт PNG | коннектор **Canva** (создать дизайн → загрузить ассеты → экспорт) → `marketing/<id>/canva/` | по тарифу Canva |
| 9 | **Проверка каждого кадра**: товар тот же (цвет, ширина, число лент), применение правильное, нет чужих логотипов, нет «латекса» для TPE, текст читается с телефона. ИИ-картинки Canva часто рисуют не тот товар (было: тканевая мини-резинка вместо петли) — такие кадры заменять нашими фото | просмотр + `docs/wb_help/` (от 700×900 px, 3:4, до 10 МБ) | 0 |
| 10 | **Загрузка в карточку WB** — только после «да» пользователя | `src/wb_card.py` / кабинет | 0 |

**Если коннектор Canva не подключён:** сказать пользователю, как включить (Настройки → Коннекторы → Canva), и до этого
сделать запасной вариант — HTML-вёрстка и рендер в Edge/Chrome (`python marketing/<id>/v2/build.py`, образец `marketing/249/v2/`).

## Что получите
1. Список конкурентов и листы их галерей (WB и Amazon).
2. Разбор: какие слайды у всех, что делает Amazon, где пробел, что поменять в самом товаре.
3. Бриф 10 слайдов.
4. 10 слайдов из Canva (PNG 900×1200) + ссылка на дизайн в Canva для правок.
Полный текст разбора — в чате, файлы — в `marketing/<id>/`.

## Что можно поменять
| Что | Где |
|---|---|
| Как отбирать конкурентов (цена, слова, сколько) | аргументы шага 1 |
| Английский запрос для Amazon | аргумент шага 3 |
| Стиль и тексты слайдов | бриф в `marketing/<id>/research/analysis_*.md` |
| Фирменные цвета и шрифты | бренд-кит в Canva |

## Режим «без образца» (решение пользователя 26.10.2026)
Фото — того же артикула у того же поставщика (`data/raw/supplier_images/<id>/`), фон убираем; «в деле» — нейросеть, кадры
с дорисованными ручками отклонять; нагрузка — «по данным производителя»; тестов, которых не было, не обещать;
перед загрузкой сверить фото с КП (цвет, ширина, толщина, число лент).

## Правила
Никаких обещаний, которые товар не докажет. Фото конкурентов — только для анализа, в нашу карточку не идут.
Загрузка в WB и публикация дизайна для других — только после «да».
