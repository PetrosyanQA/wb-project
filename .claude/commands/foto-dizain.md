# Фото и дизайн карточки

Запрос пользователя: **$ARGUMENTS** (ниша и товар; по умолчанию — товар из `PROJECT_STATE.md`).

## Что делает (простыми словами)
Превращает фото **нашего образца** в готовый визуал для WB: чистые фото на белом, фото «в деле», 10 слайдов галереи
с инфографикой, rich-блоки и короткое видео. Тексты на слайдах рисует код (ровная кириллица), фото — нейросеть.
Что показывать на слайдах, берётся из `/kartochka` (позиционирование, жалобы, ключевые слова).

## Как запустить
- `/foto-dizain` — полный комплект для текущего товара.
- `/foto-dizain только инфографика` / `только фото на белом` / `видео` — отдельный блок.

## Что нужно от вас
**Фото нашего образца** (с телефона хватит) по чек-листу из шага 1. Без образца можно сделать только «КОНЦЕПТ» из фото
поставщика — для проверки идей, но не для публикации.

## Шаги
| # | Шаг | Чем | Стоимость |
|---|---|---|---|
| 1 | **Чек-лист съёмки** образца: белый фон спереди / сбоку / сверху, комплект целиком, крупно шов и маркировка нагрузки, в руке (масштаб), в деле (турник, нога в петле), тест (груз ×2) на видео | инструкция в чат | 0 |
| 2 | **Обработка**: убрать фон, выровнять свет, увеличить качество | Saleflow Photo Editor: `python -m src.mkt gen --mode remove-bg / upscale` | по тарифу Saleflow |
| 3 | **Фото «в деле» и фотосессия**: товар тот же (цвет, ширина, форма), применение физически правильное | `python -m src.mkt gen --mode photoshoot / freeform` | по тарифу |
| 4 | **10 слайдов галереи** по брифу из `/kartochka`: 1 — главное обещание и цифра; 2 — что в комплекте; 3 — таблица «вес → лента»; 4 — тест прочности; 5 — материал TPE против латекса; 6 — как использовать; 7 — для кого; 8 — размеры; 9 — ответы на возражения из отзывов; 10 — гарантия/уход | `python -m src.mkt compose marketing/<id>/slides/<n>.json` (текст рисует код) | 0 |
| 5 | **Rich-контент**: 5–6 блоков (800×500 / 700×700 / 700×900) | `compose` | 0 |
| 6 | **Видео** 15–30 с: тест прочности + применение (съёмка образца + монтаж) | при необходимости — скилл video-shotcraft с GitHub (бесплатный, Remotion), ставим после проверки кода | 0 |
| 7 | **Проверка каждого кадра**: товар не искажён, нет чужих логотипов, текст читается с телефона, цифры только из [факт]; требования WB — jpg/png/webp, от 700×900 px (лучше 900×1200, 3:4), до 10 МБ | просмотр + `docs/wb_help/` | 0 |
| 8 | **Загрузка в карточку** — только после «да» пользователя | `src/wb_card.py` / кабинет | 0 |

## Что получите
Папка `marketing/<id>/` — фото, слайды, rich-блоки, видео; превью каждого кадра в чате; список, что переснять.

## Что можно поменять
| Что | Где |
|---|---|
| Тексты и порядок слайдов | `marketing/<id>/slides/*.json` |
| Цвета, шрифты, плашки | шаблон в `src/mkt.py` (`compose`) |
| Режимы и бриф генерации фото | `marketing/<id>/brief_*.txt` |

## Правила
Фото поставщика или конкурентов — только с пометкой «КОНЦЕПТ», в карточку идёт **наш** образец.
Никаких обещаний, которые товар не докажет (нагрузка — только после нашего теста).
