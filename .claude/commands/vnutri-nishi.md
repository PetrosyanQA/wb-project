# Внутри ниши (тип товара → цена → конкретная модель)

Запрос пользователя: **$ARGUMENTS** (номер ниши или название; по умолчанию — ниша из `PROJECT_STATE.md`).

## Что делает (простыми словами)
Ниша уже выбрана (например, 437 «Кисти косметические»). Скилл **разбирает её изнутри**: какие типы товаров там продаются
(наборы с подставкой, топорики, шинковки, японские ножи…), сколько каждый тип продаёт, есть ли в нём монополия, как продают
новички, какая прибыль при белом ввозе. Потом берёт лучший тип, ищет в нём **цену без монополии**, растущие модели, жалобы
покупателей и цену на 1688 — и выдаёт **конкретный товар** (что именно, комплект, цена, ¥-потолок).

## Как запустить
- `/vnutri-nishi 437` — разобрать нишу 437.
- `/vnutri-nishi 437 наборы с чехлом` — сразу разобрать один тип.

> ⛔ **Стоп-решение (аудит 2026-11-01):** тип товара в нише 437 выбран (набор кистей с подписями) и заморожен до 2026-12-01 /
> итогов тестовой партии. Повторный разбор 437 «с нуля» и смену типа не делать; новые идеи — в «копилку» (`docs/kopilka.md`).

## Правила пользователя (не нарушать)
Белый импорт YUAN EXIM, FBS, налог 10 %, маржа по цене продавца; **запрет один — магниты**; ЧЗ (в т.ч. детские игрушки 9503 с 01.12.2025),
декларации, электроника, батареи — можно, но с пометкой «что оформить»; уникальность — обязательна (живая выдача `wb_check_rates`); копии брендов не берём. Выбор — по **общей прибыли** (прибыль/шт × продажи новичка P25), не по марже.

## Что получите
1. **Карту ниши**: таблица типов товара с вердиктом ✅ / ⚠️ / ❌.
2. **1 конкретный товар + 2 запасных внутри ниши**: тип, комплект, цена, ¥-потолок, прибыль/шт и в месяц (P25 и P50), риск,
   жалоба, которую исправляем, 3–5 офферов 1688, лидер и новичок-ориентир.
3. Отчёты: `reports/niche_inside_<id>_<дата>.md` (+ по типу), полный текст — в чате.
4. **Следующий шаг** — обычно `/zakupka` (письмо поставщику отправляет пользователь).

## Честно: ограничения
- Тип определяется по словам названий: «нож» и «кухонный» есть почти везде — такие типы бесполезны; смотреть пары слов и карточки глазами.
- Если у карточек нет габаритов, объём = 2 л [допущение] (помечен «*») — для финалиста проверить по карточкам WB (шаг 3).
- ¥ = 11 % цены [допущение] до шага 7; решение — только по реальным ценам 1688/КП.
- Продажи — июль 2026 (Saleflow после июля неполный); сезон — `niche_deep report` (раздел 1).
