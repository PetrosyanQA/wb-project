# Папка «Алгоритм WB»

Здесь собрано всё, что мы знаем **из данных** о том, как WB ранжирует карточки и что меняется со временем.
Отчёты — на армянском (правило проекта), этот README — на русском.

## Что внутри
| Файл | Что это |
|---|---|
| `WB_ALGORITHM_2026-10-08.md` / `.pdf` | **Главный отчёт:** что влияет на позицию и продажи, как быстро WB реагирует на рекламу/цену/акции/дефектуру, что изменилось за год (комиссия, доля рекламы), часы продаж |
| `wb_algorithm_data_2026-10-08.xlsx` | Таблицы: драйверы, кривые реакции по дням −7…+14, изменения по месяцам, часы |
| `data/drivers.json` | Регрессия «внутри карточки» (329 карточек, 56 841 карточко-день) + знаки по каждой нише |
| `data/response.json` | Кривые реакции продаж и позиции на события |
| `data/changes.json` | Помесячно: комиссия FBS/FBO, % дней с рекламой/акциями, доля запросов из рекламы, скидка, склады, внешняя реклама |
| `data/novelty.json`, `data/hours.json` | Флаг «новинка», часы пиковых продаж |
| `data/marketing777.json` | Калькулятор цена × ДРР → маржа, СПП ниш, чувствительность к комиссии |

## Связанные отчёты
- `reports/marketing_strategy_777_2026-10-08.md/.pdf` — **реклама, ДРР, СПП, цена, акции: рабочая стратегия для 777** (на основе этой папки).
- `reports/winners_playbook_2026-10-08.md/.pdf` + `reports/launch_patterns_2026-10-08.xlsx` — как заходили 84 победителя в 7 нишах.

## Как обновлять
```bash
python -m src.catalog        # пересобрать каталог данных после нового сбора
python -m src.wb_algo        # пересчитать data/*.json и xlsx
python -m src.marketing777   # пересчитать маркетинг-калькулятор (после смены комиссии/закупки)
```
После обновления дописать строку в «Փոփոխությունների պատմություն» в главном отчёте: что изменилось.

## Чего здесь нет (и почему)
- Расходов конкурентов на рекламу (ДРР конкурентов): Saleflow показывает только факт рекламы (`in_ads`), не бюджет.
- Внутренней формулы WB: мы видим реакцию позиции и продаж, а не сам алгоритм.
- Августа–сентября 2026: данные Saleflow за эти месяцы неполные.
