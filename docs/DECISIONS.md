# Որոշումների մատյան

- 2026-10-18 — Ուսումնասիրվեց միջազգային պրակտիկան ապրանքի ընտրության հարցում (`reports/international_practices_2026-10-18.md`)։ Եզրահանգում. մեր կոնցենտրացիայի, նորեկների և բողոքների ֆիլտրերը ավելի խիստ են, քան Amazon-FBA ստանդարտը։ Բացակայում են «կարծիքների պատի» (top-10-ում ≥ 3 քարտ < 300 կարծիքով) և ROI ≥ 100 % դարպասները. դրանք առաջարկված են, բայց կիրառված չեն։
- 2026-10-18 — Ուսումնասիրվեց WB-ի պրակտիկան 2025–2026 (`reports/wb_best_practices_2026-10-18.md`)։ Եզրահանգում. մեր մարժայի, կոնցենտրացիայի և ЧЗ-ի ֆիլտրերը համապատասխանում են նորմային կամ ավելի խիստ են; չենք չափում վաճառք ունեցող ապրանքների %-ը, օբորոտը, CPC-ն; պարտիան՝ 150 (ոչ 300); самовыкуп-ներ՝ ոչ; պլանը՝ 731 (777-ը դուրս է մագնիսի կանոնով)։ Bright Data-ն՝ մինչև 100 կրեդիտի մնացորդ (օգտատիրոջ որոշում)։
