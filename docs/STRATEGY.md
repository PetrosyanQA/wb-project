# Ռազմավարություն՝ «սարահարթ + շատ վաճառող + լուծելի բողոք»

## Ինչու հինն էր սխալ

Սկսնակների ստանդարտ խորհուրդն է՝ «գտիր աճող նիշա»։ Տվյալները դրան հակասում են.

| Նիշայի տիպ | Ինչ է իրականում լինում | Ինչու $2,000-ով այնտեղ տեղ չկա |
|---|---|---|
| 🚀 Արագ աճող (+40%/տարի) | գրեթե միշտ պահում է **մեկ վաղ խաղացող**, որը մտել է 8–14 ամիս առաջ | նա արդեն ունի 2,000 կարծիք և գովազդային բյուջե. դու մրցում ես ոչ թե ապրանքով, այլ փողով |
| 📉 Դիվերսիֆիկացված, շատ վաճառող | սովորաբար **արդեն ընկնում է** — դրա համար են բոլորը ներս մտել | մտնում ես հերթի վերջում, գները ցած են գնում |
| ➖ **Սարահարթ + շատ վաճառող + բողոք** | պահանջարկը **ապացուցված և կայուն** է, ոչ ոք չի գերիշխում, գնորդը դժգոհ է կոնկրետ բանից | ✅ **քո տեղը** |

Սարահարթը ձանձրալի է թվում, բայց հենց դա է նորեկի համար միակ դաշտը, որտեղ **ապրանքի բարելավումը** հաղթում է գովազդային բյուջեին։

## Թիրախային պրոֆիլը (ճշգրիտ թվերով)

| Պարամետր | Թիրախ | Ինչու |
|---|---|---|
| Տրենդի թեքություն | **−1.5 … +4 %/ամիս** | սարահարթ. ոչ անկում, ոչ պայթյուն |
| YoY պիկ ամսով | **≥ −5%**, իդեալը +5…+15% | տարեկան կտրվածքը սեզոնը չի խաբում |
| Վաճառողների թիվ | **≥ 30** | շուկան բաշխված է, մուտքը բաց է |
| Տոպ-10-ի բաժին | **≤ 40%** | ոչ մի մոնոպոլիա |
| Տոպ-1 վաճառող | **≤ 25%** | չկա «թագավոր», որին պետք է տապալել |
| Տոպ-20-ի մեդիան ռեյտինգ | **≤ 4.75** | ≥4.8 = գնորդը գոհ է → բարելավելու տեղ չկա |
| Նույն թեմայով բողոք | **≥ 12%** բացասականներից | սա քո մուտքի սեպն է |
| Գին | **1,000–2,500 ₽** | ներքևում լոգիստիկան ուտում է, վերևում՝ ավելի մեծ խմբաքանակի ռիսկ |
| Ծավալ | **≤ 1 լ** | լոգիստիկա+պահեստավորում ≤25% գնից |
| Մարկավորում/սերտիֆիկատ | **չկա** | առաջին ապրանքի համար ավելորդ ծախս և ռիսկ |

## Մեխանիկան՝ «լուծելի բողոք»

Սա ռազմավարության սիրտն է։ Հերթականությունը.

```
1. Գտիր բողոքը        → sku_audit, տոպ-10-ի 1-3 աստղանի կարծիքները
2. Ստուգիր կրկնելիությունը → նույն թեման ≥12% բացասականներում, ≥3 տարբեր վաճառողի մոտ
3. Ստուգիր լուծելիությունը → կարելի՞ է փակել մատակարարի մակարդակում, առանց գինը բարձրացնելու >15%
4. Փակիր ապրանքում     → բրիֆ մատակարարին. կոնկրետ փոփոխություն, ոչ թե «ավելի լավ որակ»
5. Հայտարարիր առաջին էկրանին → ինֆոգրաֆիկայի 1-ին սլայդը = բողոքի պատասխանը
```

**Օրինակ (թերմոսներ).** Բողոքը՝ «չի պահում ջերմությունը 6 ժամից ավել»։ Հանդիպում է
տոպ-10-ի 5 վաճառողի կարծիքներում, բացասականների ~18%-ում։ Լուծում՝ կրկնակի պատ +
ավելի լավ խցան (ինքնարժեքում +8%)։ Առաջին սլայդ՝ «12 ժամ՝ 71°C» ջերմաչափի լուսանկարով։
Սա **չի** պահանջում գովազդային բյուջե՝ գերազանցելու լիդերին. այն փոխում է ընտրության պատճառը։

### Երբ բողոքը ՉԻ աշխատում (ազնիվ)

- Բողոքը առաջանում է **գնի** պատճառով (էժան նյութ) → ուղղելը գինը հանում է միջանցքից
- Բողոքը WB-ի մասին է (առաքում, ջարդված տուփ) → քո վերահսկողությունից դուրս
- Լիդերը **արդեն ուղղել է** այն (նայիր նրա վերջին 2 ամսվա կարծիքները, ոչ թե բոլորը)
- Բողոքը 5%-ից քիչ է → դա աղմուկ է, ոչ թե օրինաչափություն

## Ֆիլտրերի շարքը՝ էժանից թանկ

```
regulatory  →  economics  →  concentration  →  yoy_peak  →  profile  →  audit
  0 հարց.      0 հարց.         1 հարց.          1 հարց.      0 հարց.    20 հարց.
```

Առաջին ՉԱՆՑԱԾ դարպասը կանգնեցնում է շղթան։ «Честный знак»-ի ենթակա նիշան դուրս է
մնում **զրո API հարցումով** — ոչ թե 500 քարտ քաշելուց հետո։

```bash
python -m src.gates --path "Дом/Хранение вещей/Органайзеры" --volume 0.8
```

## Բյուջեի մաթեմատիկան (1,000–2,500 ₽, ≤1 լ)

| | 1,200 ₽ ապրանք | 2,200 ₽ ապրանք |
|---|---|---|
| Ինքնարժեք (30%) | 360 ₽ | 660 ₽ |
| Լոգիստիկա+պահեստ | ~75 ₽ (6%) | ~80 ₽ (4%) |
| Առաջին խմբաքանակ $2,000×0.55 | **~290 հատ** | **~158 հատ** |
| Break-even գին | ~800 ₽ | ~1,430 ₽ |
| Պաշար մինչև մեդիան | 33% | 35% |

Երկուսն էլ տեղավորվում են։ 2,000 ₽-ի գոտում մրցակցությունը սովորաբար ավելի թույլ է,
բայց պահանջում է ավելի լավ ինֆոգրաֆիկա։

## Kill criteria — երբ դուրս գալ

- Լիդերը 2 ամսում փակել է բողոքը → քո սեպը չքացավ
- Նոր ուժեղ խաղացող վերցրել է >15% բաժին → սարահարթը դառնում է մրցավազք
- YoY պիկ ամսով ընկել է <−10% → նիշան մեռնում է
- Քո ինքնարժեքը բարելավումից հետո >38% գնից → տնտեսությունը չի տանում
- 60 օրում выкуп <70% → ապրանքը չի համապատասխանում ակնկալիքին

## Շաբաթական ցիկլ

```bash
python -m src.discover --depth 2 --probe 25 --growth-top 10   # նոր թեկնածուներ
python -m src.gates --path "<տոպ-1>" --volume 0.8             # դարպասներ
python -m src.trend_scan --path "<տոպ-1>" --days 540          # պատմությունը → history.db
python -m src.sku_audit --sku <id> --sku <id>                 # բողոքի մայնինգ
python -m src.unit_econ --price X --cost Y --volume Z         # վերջնական թիվը
```

Ամեն գործարկում կուտակվում է `data/history.db`-ում։ 3 ամիս հետո կունենաս քո սեփական
ժամանակային շարքը, որը ոչ մի ծառայություն քեզ չի տա։
