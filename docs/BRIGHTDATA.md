# Bright Data в проекте (с 2026-10-18)

| Параметр | Значение |
|---|---|
| Продукт | Web Unlocker, зона `web_unlocker1` (единственная активная) |
| Ключ | только `.env` → `BRIGHTDATA_TOKEN` (никогда в чат/отчёты/git) |
| Бесплатно | 5 000 кредитов/мес, обновление 1-го числа; 1 страница ≈ 1 кредит. Прокси НЕ входят ($5 тест, 30 дней) — не используем |
| Бюджет | 5 000 кредитов/мес − резерв 100 (решение пользователя 2026-10-18: тратить по необходимости, остановиться и сообщить при остатке 100); `usage` показывает остаток |
| Кэш | `data/raw/brightdata/<дата>/<имя>.html`; повтор в тот же день = 0 кредитов; пустой ответ не кэшируется |
| Код | `src/brightdata_client.py` (`ping`, `get`, `s1688`, `usage`) |

## Что можно делать

| Задача | Источник | Статус |
|---|---|---|
| Цены поставщиков | 1688 поиск (`s1688`) — ¥, продажи, % повторных покупок | ✅ работает (731, 249, 722) |
| Карточка поставщика: ступени цен, MOQ, габариты | 1688 detail | парсер не написан |
| Отзывы конкурентов Ozon / Яндекс Маркет | страницы товара | не проверено |
| Отзывы WB | публичный API WB (без Bright Data) — `src.wb_cdn_card` / feedbacks | уже есть |
| Тренды: Amazon Best Sellers / Movers & Shakers, AliExpress | страницы категорий | не проверено |
| Выдача WB/Ozon по запросу (кто в топе, цены) | страница поиска | не проверено (WB рендерит JS) |
| Google/Yandex выдача | SERP API — зоны нет, тем же ключом можно добавить в кабинете | не нужно сейчас |

Ограничения: без логина (1688/WB-кабинет), без решения капчи вручную; TikTok/Instagram — слабо (JS + логин).

«握力器 拉力器» дважды пустой, одно слово «握力器» — OK.
