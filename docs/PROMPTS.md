# Պատրաստի պրոմպտներ Claude Code-ի համար

Հիմնական կանոն. **մի խնդրիր «գտիր լավ ապրանք»**։ Տուր սահմանափակումներ, չափանիշներ և ելքի ձևաչափ։
Վատ պրոմպտը AI-ին ստիպում է հորինել, լավ պրոմպտը՝ հաշվել։

---

## 1. Սկիզբ (նոր սեսիա)

```
Կարդա CLAUDE.md-ը և docs/METRICS.md-ը։ Հետո ստուգիր API լիմիտը և ասա՝
ինչ ծավալի սքան կարող ենք թույլ տալ այսօր։ Ոչինչ մի գործարկիր առանց իմ հաստատման։
```

## 2. Նիշաների որոնում

```
Ես սկսնակ WB վաճառող եմ, բյուջե $2,000, ուզում եմ ոչ-սեզոնային, ոչ-չափսային,
<1 լիտր ապրանք 700–3,500 ₽ միջանցքում։
Վերցրու այս կատեգորիաները՝ "Дом/Кухня", "Спорт", "Автотовары".
Ամեն մեկի համար գործարկիր niche_scan --dry-run, ցույց տուր ինձ պլանը և հարցումների քանակը,
սպասիր հաստատմանս, հետո կատարիր և տուր տոպ-5 նիշա՝ սքորով և մերժման պատճառներով։
```

## 3. Կասկածի ստուգում (ամենակարևոր պրոմպտը)

```
Վերցրու reports/niche_scan_<date>.md-ի #1 նիշան և փորձիր ԽԱԽՏԵԼ այն.
գտիր 5 պատճառ, թե ինչու այս նիշան կարող է թակարդ լինել սկսնակի համար։
Ամեն պատճառի տակ դիր տվյալ data/raw/-ից։ Եթե պատճառը չես կարող տվյալով հիմնավորել՝ ասա դա ուղիղ։
```

## 4. Մրցակիցներից ապրանքի բրիֆ

```
Վերցրու այս նիշայի տոպ-2 քարտերի կարծիքները (items/<id>/comments)։
Հանիր կրկնվող բողոքները, խմբավորիր ըստ պատճառի և սարքիր "ապրանքի բրիֆ"՝
ինչով է մեր տարբերակը տարբերվելու, և ինչքանով դա կբարձրացնի ինքնարժեքը։
Ելք՝ աղյուսակ (բողոք | հաճախություն | մեր լուծումը | +ինքնարժեք ₽)։
```

## 5. Յունիտ-էկոնոմիկա 3 սցենարով

```
Գործարկիր unit_econ երեք սցենարով՝ բազային (նիշայի մեդիան գին),
հոռետեսական (գին −15%, выкуп −15 տոկոսային կետ, ДРР 22%) և
լավատեսական (գին +10%, ДРР 10%)։ Տուր մեկ աղյուսակ երեք սյունով և ասա՝
որ սցենարում ենք կորցնում փողը և ինչ պայմանով։
```

## 6. Վերջնական որոշում

```
/decide
```
կամ ձեռքով.
```
Հավաքիր ամբողջը մեկ որոշման փաստաթղթում՝ 1 առաջարկվող ապրանք + 2 պահեստային։
Ամեն մեկի համար՝ նիշայի մետրիկաներ, յունիտ-էկոնոմիկա, խմբաքանակի պլան $2,000-ի տակ,
3 ռիսկ մեղմացումով և kill criteria 30 օրվա համար։
Գրիր reports/decision_<date>.md ֆայլում, հայերեն։
```

## 7. Ամենշաբաթյա մոնիտորինգ

```
Գործարկիր niche_scan նույն նիշաների վրա, համեմատիր անցյալ շաբաթվա հաշվետվության հետ
և տուր միայն ՓՈՓՈԽՈՒԹՅՈՒՆՆԵՐԸ՝ ինչ է աճել/ընկել >15%, նոր խաղացողներ տոպ-10-ում,
գնային տեղաշարժեր։ Առավելագույնը 10 տող։
```
