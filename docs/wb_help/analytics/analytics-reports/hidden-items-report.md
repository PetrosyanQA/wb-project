# Отчёт «Скрытые товары»

Скачано: 2026-10-20

---

Обновлено 23.07.2026Отчёт «Скрытые товары»

Отчёт показывает, какие карточки товаров были заблокированы — например, потому что содержат неприемлемый контент или нарушают авторские права.

Если карточка заблокирована, товар снимается с продажи. Он будет автоматически отправлен на возврат в выбранный пункт выдачи. Информацию об этом вы увидите в разделе Возвраты товаров покупателями.

Если заблокированный товар продавался по схеме «Маркетплейс» (продажа со склада продавца), обязательно обнулите остатки на данные позиции. Это можно сделать в разделе Поставки и заказы  →  Маркетплейс (FBS)  →  Управление остатками 

Данные представлены в виде таблицы, в которой можно увидеть бренд, артикул WB, наименование товара, артикул продавца, отдел, который произвёл блокировку, а также причину блокировки. 

[img:]

Вы можете посмотреть данные по всем карточкам сразу, отфильтровать их по бренду или скачать таблицу в формате XLSX-файла. 

Также некоторые карточки могут быть временно скрыты из выдачи из-за низкого рейтинга магазина. Данные по таким карточкам можно увидеть в отчёте «Оценка товара».
