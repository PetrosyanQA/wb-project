# Сводный отчёт по продавцу

Категория: analytics / analytics-reports
Скачано: 2026-10-20

---

Обновлено 18.05.2026Сводный отчёт по продавцу

Отчёт отображает основные показатели по продажам и обороту продавца без разбивки по брендам и номенклатурам, то есть являясь сводным по контрагенту. Данные приведены в виде таблицы.

[img:image.png]

Вы можете выбрать показатели, которые хотите видеть в таблице, нажав кнопку «Настроить таблицу».

Нажмите на стрелочку возле года в первой колонке таблицы, чтобы развернуть данные и посмотреть отчёт по месяцам.
