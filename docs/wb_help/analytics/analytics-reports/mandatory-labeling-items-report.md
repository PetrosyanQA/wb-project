# Отчёт по товарам с обязательной маркировкой

Категория: analytics / analytics-reports
Скачано: 2026-10-20

---

Обновлено 18.05.2026Отчёт по товарам с обязательной маркировкой

После того, как вы продали товары, промаркированные КИЗ, в этом отчёте вы получаете информацию о том, какие из кодов были проданы. 

[img:image.png]

Выберите диапазон дат и страну, чтобы увидеть данные. Таблицу можно выгрузить и сохранить на компьютер в виде Excel-документа.

При доставке на склады Wildberries товары, которые подлежат обязательной маркировке, продавец получает сведения о кодах маркировки (КИЗ) по отгруженным товарам. 

По актам приёмки УПД «ДОП» формируется автоматически. Скачайте документ «УПД по маркировке» из раздела «Документы» в профиле на портале. После ознакомления отправьте нам файл в формате XML через вашего оператора ЭДО.
