Главное о цессии

Цессия — это уступка права требования долга от одного лица другому, то есть замена кредитора.  

С 19 мая некоторые договоры из ООО МКК «ВБ Финанс» по договору цессии перейдут в ООО «ВБ Банк». При этом условия договора (ставка, график платежей, условия частичного досрочного погашения) не изменятся; поменяются только реквизиты для оплаты — на реквизиты WB Банка.

Как списываются платежи

Платежи по договору будут списываться с баланса продавца. Новые реквизиты автоматически появятся в личном кабинете на сайте WB Finance. По старым реквизитам внести платёж не получится. Проданный по цессии договор будет закрыт в ООО МКК «ВБ Финанс». 

Вы можете самостоятельно внести платёж по договору по новым реквизитам, указанным в личном кабинете на портале WB Finance. 

Если у вас несколько договоров — один с WB Finance, а другой с WB Банком — сначала спишется платёж по договору с WB Finance.

Где посмотреть новые реквизиты

Чтобы посмотреть новые реквизиты, на главной странице сайта WB Finance нажмите на баннер с договором займа, проданным по цессии → Пополнить баланс для займов WB Банка.

Информация о договоре

Договор, проданный по цессии, будет отображаться в личном кабинете на сайте WB Finance со статусом «WB Банк».

[img:]

По договорам WB Банка деньги будут списываться с баланса продавца. Его можно пополнить по реквизитам банка, указанным в личном кабинете, либо перевести необходимую сумму непосредственно по реквизитам, указанным в уведомлении о цессии.

[img:]

В какую поддержку обращаться

Если у вас один договор и он передан по цессии WB Банку, то вы можете обращаться в поддержку банка services@wb-bank.ru. 

Если у вас несколько договоров и один из них остался в WB Finance, а другой перешёл в WB Банк, то в первом случае обращайтесь в чат поддержки WB Finance на сайте WB Finance, а во втором — в поддержку банка services@wb-bank.ru.
