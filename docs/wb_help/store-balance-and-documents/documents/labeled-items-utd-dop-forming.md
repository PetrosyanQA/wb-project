Обновлено 18.05.2026Формирование УПД «ДОП» на товары с обязательной маркировкой для поставок типа «Короб»

Эта инструкция — про формирование УПД «ДОП» для поставок типа «Короб». Про формирование УПД «ДОП» для товаров с агрегированными КИЗ, которые отгружаются поставками типа «Монопаллета», есть отдельная инструкция: «Передача кодов маркировки при отгрузке поставок типа «Монопаллета». 

Подробнее о КИЗ и маркировке читайте в инструкции «Как продавать товары с КИЗ»

Когда продавец реализует товары с обязательной маркировкой по модели «Склад WB» (FBW), Wildberries самостоятельно выводит и, при необходимости, возвращает в оборот их КИЗ. Для этого продавцу нужно передать коды маркировки через универсальный передаточный документ — УПД «ДОП», или УПД по маркировке.

Если вы продаёте товары с КИЗ по модели «Маркетплейс» (FBS), передавать УПД «ДОП» Wildberries не нужно. Вместо этого добавьте КИЗ товара в сборочном задании по алгоритму из пункта «КИЗ». Вывести код из оборота тоже нужно самостоятельно через сервис «Честный знак»

Как работать с УПД «ДОП»

1. Ознакомьтесь с актом приёмки

УПД «ДОП» выставляется к акту приёмки, если в поставке были товары с КИЗ

Перейдите в раздел Поставки, выберите принятую поставку типа «Короб» и кликните по ней, чтобы открыть детализацию. 

[img:]

В правом верхнем углу нажмите «Скачать документы» и выберите «Акт приёмки». 

[img:]

На ваше устройство загрузится zip-архив, внутри — акт приёмки в формате .xlsx и файл электронной подписи .sig. 

Все документы Wildberries подписываются усиленной квалифицированной электронной подписью, которая подтверждает их подлинность. К каждому документу прикладывается файл электронной подписи в формате .sig — проверить ее корректность можно на сайте Госуслуг

В акте приёмки можно увидеть номер документа, дату выставления и коды маркировки товаров в 6-ом столбце:

[img:]

Сформированные акты приёмки хранятся и в разделе Документы — там их можно найти по фильтрам или номеру. 

[img:]

2. Скачайте черновик «УПД по маркировке»

В течение суток после того, как вы получите акт приёмки, черновик УПД «ДОП» появится в разделе  Документы в профиле на портале. Черновик называется «УПД по маркировке» в формате .xml. Номер «УПД по маркировке» — такой же, как у акта приёмки, к которому выставлен УПД. 

[img:]

3. Заполните УПД

С 1 апреля 2025 года обмен документами должен происходить в специальном формате, который утверждён приказом ФНС № ЕД-7-26/970@ от 19.12.2023.

Это стандартизированный XML-шаблон, по которому формируются УПД для обмена через ЭДО. Формат устанавливает строгие правила: какие поля и коды обязательны, чтобы системы ФНС и других участников ЭДО могли правильно прочитать и обработать документ

Заполнение данных для отправки УПД происходит внутри вашей системы ЭДО. Все необходимые поля уже есть в интерфейсе, но у разных провайдеров могут отличаться названия и внешний вид этих полей. В этой инструкции приведём примерные названия полей.

4. Отправьте УПД

После заполнения отправьте XML-файл через вашего оператора ЭДО. Если вы не подключены к ЭДО Wildberries, подайте запрос на подключение через операторов ЭДО Диадок или СБИС. 

Если вы отправляете УПД «ДОП» через Диадок, чтобы данные передавались в ГИС МТ автоматически, нужно подключить сервис передачи данных. 

Оптимальный срок передачи УПД — 3 рабочих дня с даты размещения акта приёмки на портале. Если вы не укладываетесь в этот срок, мы всё равно будем ждать от вас отправку документа, но не дольше 3 месяцев с даты формирования акта

ЭДО Лайт

Пользователям ЭДО Лайт доступен автоматически сформированный CSV-файл для передачи УПД. Его можно скачать в детализации поставки в разделе Поставки.

Документ полностью готов к использованию после загрузки с портала. Пожалуйста, убедитесь, что вы скачали и открываете файл именно в формате .csv

Затем этот файл можно использовать для создания УПД в личном кабинете ЭДО Лайт — загрузите его в поле «Сведения о маркировке». Подробнее о том, как работать с CSV-файлами, читайте в базе знаний вашего оператора.

Wildberries не принимает документы, отправленные напрямую в ЭДО Лайт. Если вы отправляете УПД «ДОП» из ЭДО Лайт, настройте роуминг для передачи в Диадок. Инструкция по настройке роуминга есть на сайте «Честный Знак».

Если вы самостоятельно создаёте УПД, ориентируйтесь на особенности заполнения, которые указаны в этой инструкции, а также на базу знаний вашего оператора ЭДО. 

Wildberries не принимает корректировочные документы (УКД). При отказе в подписи необходимо отправить УПД по маркировке повторно
