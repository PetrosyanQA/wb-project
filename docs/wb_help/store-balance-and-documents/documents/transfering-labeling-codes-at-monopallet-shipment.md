Обновлено 04.09.2026Оформление УПД для маркированных товаров в поставках типа «Монопаллета»

Если вы поставляете товары с обязательной маркировкой «Честный знак» (КИЗ), порядок оформления УПД зависит от того, какой учёт применяется для вашей категории товаров — поэкземплярный (с КИЗ) или объёмно-сортовой (ОСУ).  

Подробнее о том, какие товары подлежат маркировке, можно узнать на официальном сайте «Честного знака»

Товары с поэкземплярным учётом (КИЗ)

Для таких товаров используйте агрегированный код маркировки транспортной упаковки — КИТУ.

Агрегация — это объединение нескольких товаров одного баркода в транспортную упаковку с единым кодом маркировки. Этот код содержит информацию обо всех вложенных кодах маркировки.

Агрегированный код получают в системе GS1. В GS1 он называется SSCC — Serial Shipping Container Code, затем передают в «Честный знак». При передаче данных в «Честный знак» указывают:

- ИНН продавца,

- сформированный SSCC,

- все коды маркировки, которые входят в агрегированный код.

Оператор маркировки проверяет агрегированный код на уникальность.

Важные правила:

- в один КИТУ можно объединять только товары с одним кодом ТН ВЭД;

- КИТУ состоит только из цифр, буквы не используются;

- в одной упаковке должны быть коды маркировки одного статуса

Чтобы оформить поставку с маркированным товаром, нужно настроить отгрузку агрегированными КИЗ в системе «Честного знака» по образцу:

Подробнее читайте в инструкциях «Честного знака»: 

- Агрегирование маркированного товара, 

- Транспортная упаковка

Отгрузка монопаллет с агрегированными КИЗ

Шаг 1. Создайте поставку

- Выберите тип поставки «Монопаллета».

- Укажите количество монопаллет и дату поставки.

- На этапе «Упаковка и печать штрихкодов» скачайте шаблон. Используйте агрегированный КИЗ вместо штрихкода паллеты. Агрегированый КИЗ содержит информацию обо всех КИЗ на конкретной паллете. 

[img:]

- В файле укажите:

- баркод,

- количество товара,

- агрегированный КИЗ,

- срок годности (если есть).

Агрегированный КИЗ нужно указывать в текстовом формате, без скобок «(» и «)». Сохраняйте все нули — код должен точно совпадать с тем, что присвоен в «Честном знаке»

[img:]

- Загрузите файл с кодами. 

Шаг 2. Наклейте коды

- Вместо обычного ШК паллеты наклейте на монопаллету агрегированный КИЗ. 

На одной паллете можно разместить до 3 баркодов. Для одной паллеты можно указать только 1 агрегированный КИЗ. Дублировать их на несколько паллет нельзя, иначе при приёмке могут возникнуть ошибки

- Проверьте, что коды отображаются на вкладке «Упаковка и печать штрихкодов» при создании поставки. Все коды должны быть уникальными.

Шаг 3. Отгрузите поставку

- Заполните раздел «Пропуска и ШК поставки».

- Дождитесь статуса «Отгрузка разрешена».

- Отгрузите поставку в запланированную дату.

ШК поставки и упаковочный лист обязательны — как в обычной поставке

Оформление УПД «ДОП»

После того как товары примут в пункте отгрузки Wildberries, агрегированные коды появятся в акте приёмки — в колонке «ШК короба». 

1. Скачайте акт приёмки

Акт можно скачать в течение суток после завершения приёмки в разделе «Поставки» → детализация поставки → «Скачать документы» → «Акт приёмки». 

[img:]

2. Скачайте черновик УПД «ДОП»

УПД «ДОП» автоматически появится в разделе «Документы» после формирования акта приёмки. Отправить УПД нужно через ЭДО не позднее 3 рабочих дней от даты акта приёмки. 

3. Укажите агрегированные коды в УПД

Коды указываются в теге «ИдентТрансУпак=».

4. Проверьте данные

Код в УПД должен полностью совпадать с кодом в акте приёмки. Если код не совпадает, УПД отклоним.

Агрегированный код может содержать 18 или 20 символов — это зависит от идентификатора применения. Идентификатор применения — это набор из двух или более знаков, расположенный в начале строки. 

Wildberries самостоятельно выводит из оборота и возвращает в оборот КИЗ

Если при планировании поставки вы ещё не знаете точный список КИЗ, вы всё равно можете создать поставку. Добавьте агрегированный КИЗ позже — как только узнаете состав отправляемых кодов.

Перед отгрузкой обязательно заполните все коды. Если этого не сделать, мы не сможем принять товар

Товары с передачей по ОСУ (объёмно-сортовой учёт)

ОСУ — это учёт товара не по каждой единице, а по количеству в целом. В этом случае агрегацию создавать не нужно. Передают только:

- код GTIN,

- количество единиц.

Коды маркировки отдельных экземпляров в «Честный знак» не передают.

Отгрузка монопаллет с товарами по ОСУ

Создайте поставку типа «Монопаллета», оформите и отгрузите её стандартно, как для немаркированных товаров.

Оформление УПД «ДОП»

1. Скачайте акт приёмки

После сдачи товара в пункт отгрузки Wildberries акт приёмки можно скачать на портале: Поставки и заказы → Все поставки. Выберите фильтр «Принято», найдите нужную поставку и скачайте акт.

[img:]

2. Создайте УПД «ДОП»

Отправить УПД нужно через ЭДО не позднее 3 рабочих дней от даты акта приёмки. 

3. Укажите GTIN и количество товаров в УПД

В УПД для товаров по ОСУ передаются коды GTIN и количество. КИЗы указывать не нужно.

- GTIN — это штрихкод или артикул товара из 14 символов. Если символов меньше, GTIN дополняется до 14 цифр нулями;

- количество — количество единиц, которым присвоен код GTIN и которое отгружено в пункт. 

Код GTIN можно заполнить двумя способами. Он передаётся в информационном поле:

- <НомУпак> по формуле: 02[GTIN]37[Количество], где 02 и 37 — постоянные переменные;

- <ГТИН>, а в поле <КолВедМарк> — указывается количество отгруженного товара.

[img:]

[img:]

Основные поля УПД:

- <КодТов="баркод товара"> — баркод из акта приёмки;

- <КолТов="Количество товара"> — количество из акта приёмки.

<ДопСведТов ПрТовРаб="1" КодТов="баркод товара" КолТов="Количество товара" НаимЕдИзм="шт" КрНаимСтрПр="Страна производства">

Количество и баркоды должны точно соответствовать данным акта — по ним происходит автоматическая проверка.

Важные моменты по заполнению всех УПД

- получатель: ООО «РВБ», ИНН 9714053621, КПП 507401001;

- в полях «Стоимость товаров» и «Стоимость с НДС» укажите «0»;

- поле «Цена за единицу» заполнять не нужно;

- в поле «Налоговая ставка» укажите «без НДС»;

- в поле «Обоснование передачи» укажите значение «0005» (передача Агенту);

- в основании УПД укажите: наименование — «Акт приёмки товара», номер — номер акта (только цифры), дата — дата акта (в формате дд.мм.гггг).
