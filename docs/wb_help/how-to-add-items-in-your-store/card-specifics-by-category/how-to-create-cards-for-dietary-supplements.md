# Заполнение полей карточек товаров категорий «БАДы» и «Бытовая химия»

Обновлено 18.05.2026Заполнение полей карточек товаров категорий «БАДы» и «Бытовая химия»

Чтобы продавать товары в категориях «БАДы» и «Бытовая химия», в карточке нужно заполнить поля «Свидетельство о регистрации СГР» и «Торговое наименование».

Для товаров категории «БАДы» поля заполнять обязательно. Рекомендуем также заполнить поля и для категории «Бытовая химия» — в дальнейшем они тоже станут обязательными, об этом дополнительно сообщим в «Новостях»

Свидетельство о государственной регистрации (СГР)

Проверить СГР и скопировать номер вы можете в едином реестре по ссылке.

[img:image.png]

Настройка поиска:

Номер свидетельства → значок фильтра → вставить номер СГР в открывшееся поле → нажать значок галочки.

Обратите внимание на языковую раскладку букв в номере СГР:

- первые буквы AM, RU, BY, KG, KZ — английская раскладка. Буква E в номере может быть как русская, так и английская, нужно копировать номер непосредственно из реестра

СГР должен быть в статусе «Подписан и действует»

[img:image.png]

Торговое наименование

Торговое наименование — это название продукции из СГР без сокращений. Скопировать название продукции вы можете в реестре по ссылке.

Настройка поиска:

Номер свидетельства → значок фильтра → вставить номер СГР в открывшееся поле → нажать значок галочки.

После того, как по номеру СГР отобразилась запись в реестре, нажмите на значок [img:image.png] — в открывшемся окне появится полная информация о продукции. Найдите там раздел «Наименование продукции» и полностью скопируйте из него название. 

[img:image.png]

Затем вставьте его в поле «Торговое наименование» при создании карточки товара.

Если в реестре в поле «Наименование продукции» в тексте есть точка с запятой « ; », замените её на запятую « , » — тогда система корректно сохранит данные в карточке товара

Чтобы карточка прошла автопроверку, номер СГР и наименование продукции по реестру БАД должны совпадать на 100%.
