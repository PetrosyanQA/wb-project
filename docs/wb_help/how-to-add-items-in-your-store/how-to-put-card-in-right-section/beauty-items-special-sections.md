# Специальные разделы для товаров из категории «Красота»

Обновлено 18.05.2026Специальные разделы для товаров из категории «Красота»

Аксессуары

В этот раздел карточки товаров попадают по соответствующей категории в выбранном подразделе.

[img:image.png]

Волосы

Чтобы товары попали в раздел «Волосы», в поле «Назначение косметического средства» укажите параметр «Для волос».

[img:image.png]

Детская декоративная косметика

Чтобы товары попали в раздел «Детская декоративная косметика», в поле «Назначение косметического средства» напишите «Детская декоративная косметика».

[img:image.png]

Для загара

Чтобы товары попали в раздел «Для загара», в поле «Действие» укажите «Солнцезащитное».

[img:image.png]

Для мам и малышей

Чтобы товары попали в раздел «Для мам и малышей», в поле «Назначение косметического средства» напишите «Для мам и малышей».

[img:image.png]

Макияж

В эти разделы попадают товары в соответствии с параметром «Назначение косметического средства»: 

- для бровей

- для глаз

- для губ

- для лица

Уход за кожей

В этот раздел попадают товары по двум параметрам:

«Назначение косметического средства»

- для ванны и душа,

- интимная гигиена,

- для депиляции и эпиляции,

- для глаз,

- для бровей,

- для губ,

- для лица,

- для ног,

- для рук,

- для тела.

«Действие»

- против морщин,

- против акне,

- против пигментации, 

- коррекция фигуры,

- против растяжек.

Мужская линия

Внутри раздела «Мужская линия» — несколько подразделов:

[img:image.png]

Чтобы товары попали в подразделы «Для волос» или «Уход за лицом и телом», в поле «Назначение косметического средства» напишите «Мужская линия»: 

[img:image.png]

Чтобы товары попали в подраздел «Для усов и бороды», в поле «Назначение косметического средства» напишите «Для усов и бороды»:

[img:image.png]

Чтобы товары попали в подраздел «Для бритья», в поле «Назначение косметического средства» напишите «Для бритья»:

[img:image.png]

Подарочные наборы

Чтобы товары попали в раздел подарочных наборов, заполните поле «Тип подарка». 

[img:image.png]

Укажите в нём «Косметические наборы»:

[img:image.png]

Ногти

Чтобы товары попали в подраздел «Ногти», в поле «Назначение косметического средства» нужно указать «Для маникюра и педикюра»:

[img:image.png]

[img:image.png]

Гигиена полости рта

Чтобы товар попал в этот подраздел, в поле «Назначение косметического средства» напишите «Гигиена полости рта».

[img:image.png]

Инструменты для парикмахеров, косметические аппараты и средства личной гигиены

В эти подразделы попадают товары только с категорией в карточке товара, которая соответствует фильтрам:

[img:image.png]

Категории по разделу меню
