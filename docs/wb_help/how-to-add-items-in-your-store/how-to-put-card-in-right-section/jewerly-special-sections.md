Обновлено 18.05.2026Специальные разделы для ювелирных изделий

Ювелирные изделия

Почти во все подразделы категории «Ювелирные изделия» товары попадают в соответствии с указанной в карточке категорией. 

Исключение составляют три подраздела: 

- Украшения из золота,

- Украшения из серебра,

- Украшения из керамики.

В них попадают товары по указанному в карточке параметру «Состав ювелирного изделия».

Украшения из золота, серебра или керамики

Чтобы товар попал в подраздел «Украшения из керамики», в поле «Состав ювелирного изделия» напишите «Керамика». 

[img:image.png]

Чтобы товар попал в подраздел «Украшения из серебра», напишите в этом поле «Серебро». 

[img:image.png]

Чтобы товар попал в подраздел «Украшения из золота», в поле «Состав ювелирного изделия» укажите один из вариантов:

- Золото желтое,

- Золото белое,

- Золото красное,

- Золото розовое,

- Золото черное.
