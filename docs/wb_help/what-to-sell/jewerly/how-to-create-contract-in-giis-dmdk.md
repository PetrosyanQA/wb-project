Обновлено 18.05.2026Как создать договор-контракт в ГИИС ДМДК

С помощью информационной системы ГИИС ДМДК государство отслеживает все операции с ювелирными изделиями, контролирует их подлинность и легальность происхождения. 

Чтобы продавать изделия на Wildberries, продавцу нужно создать в системе договор-контракт. Для работы по модели «Склад WB» (FBW) нужно создать договор на реализацию и комиссию, а для работы по модели «Маркетплейс» (FBS) — договор на доставку.  

Начало работы в системе

Для начала работы в системе ГИИС ДМДК нужно встать на специальный учёт в Федеральной пробирной палате. Для этого создайте и отправьте заявление.

Договор на реализацию и комиссию для работы по модели  «Склад WB» (FBW)

1. Войдите в личный кабинет в ГИИС ДМДК.  

2. Выберите в левом боковом меню: Оборот объектов учёта → Контракты.

[img:]

3. В правом верхнем углу страницы нажмите «Создать» и переходите к заполнению формы.

[img:]

В графе «Внешний номер контракта поставщика» укажите Б/Н, так как Оферта Wildberries не имеет номера.

В качестве даты поставьте дату первого подписания оферты Wildberries. Её можно узнать в профиле в разделе «Оферты» → Архив оферт. 

Графа «Внешний номер контракта получателя» — Б/Н, аналогично графе «Внешний номер контракта продавца».

В графе «Тип контракта» выберите из выпадающего списка пункт «Договор на реализацию/комиссию». 

[img:image.png]

Поставьте галочку напротив пункта «Регистратор — одна из сторон контракта».

[img:]

«Поставщик» — выберите из выпадающего списка свою организацию.

«Получатель» — ООО «РВБ».

[img:]

Графы «Грузополучатель» и «Грузоотправитель» заполните по аналогии с графами «Поставщик» и «Получатель».

Графы «Общая стоимость (включая НДС)» и «Сумма НДС» заполнять не нужно

В графе «Выбор валют» выберите из выпадающего списка пункт «Российский рубль».

4. Нажмите на кнопку «Сохранить», а затем — «Зарегистрировать».

Если контракт загружен в систему корректно, он отразится в личном кабинете ГИИС ДМДК в статусе «Действует». После этого вы сможете передавать в ГИИС ДМДК информацию об операциях с изделиями.

Договор на доставку для работы по модели «Маркетплейс» (FBS)

Добавьте сведения о РВБ, как о курьерской компании, в личном кабинете в ГИИС ДМДК.  

1. Войдите в раздел «Настройки организации».

[img:]

2. В блоке «Курьерские компании» нажать кнопку «Добавить контрагента».

[img:]

3. Начните вводить РВБ в поисковой строке «Контрагенты» и выберите ООО «РВБ» в выпадающем списке. 

[img:]

4. Нажмите кнопку «Сохранить».

5. Выберите в левом боковом меню: Оборот объектов учёта → Контракты.

[img:]

6. В правом верхнем углу страницы нажмите «Создать» и переходите к заполнению формы.

[img:]

В графе «Внешний номер контракта поставщика» укажите Б/Н, так как Оферта Wildberries не имеет номера.

В качестве даты поставьте дату первого подписания оферты Wildberries. Её можно узнать в профиле на портале продавцов в разделе «Оферты» → Архив оферт. 

Графа «Внешний номер контракта получателя» — Б/Н, аналогично графе «Внешний номер контракта продавца».

В графе «Тип контракта» выберите из выпадающего списка пункт «Договор на доставку».

[img:]

Поставьте галочку напротив пункта «Регистратор — одна из сторон контракта».

[img:]

«Поставщик» — выберите из выпадающего списка свою организацию.

«Получатель» — ООО «РВБ».

[img:]

Графы «Грузополучатель» и «Грузоотправитель» заполните по аналогии с графами «Поставщик» и «Получатель».

Графы «Общая стоимость (включая НДС)» и «Сумма НДС» заполнять не нужно

В графе «Выбор валют» выберите из выпадающего списка пункт «Российский рубль»

7. Нажмите на кнопку «Сохранить», а затем — «Зарегистрировать».
