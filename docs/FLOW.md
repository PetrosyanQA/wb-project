# Ինչպես է Claude-ը անելու վերլուծությունը — քայլ առ քայլ, օրինակով

Ներքևում իրական սցենար է. ինչ ես գրում, ինչ է անում Claude-ը, ինչ ես տեսնում էկրանին։
Ընդհանուր ժամանակը՝ **1.5–3 ժամ** մեկ նիշա ընտրելու համար (ոչ թե 3 օր)։

```
   ՔՈ ՀՐԱՄԱՆԸ              CLAUDE-Ը ԱՆՈՒՄ Է                ԴՈՒ ՍՏԱՆՈՒՄ ԵՍ
──────────────────────────────────────────────────────────────────────────────
1  /niche-scan …    →   լիմիտ → path → dry-run → սքան   →   ռեյտինգ 12 նիշայի
2  «խախտիր #1-ը»    →   փնտրում է հակափաստարկներ        →   5 ռիսկ տվյալներով
3  /sku-audit …     →   5 մրցակից + կարծիքներ           →   ապրանքի բրիֆ
4  /sync-tariffs    →   WB API → իրական տարիֆներ        →   ճշգրիտ կոմիսիա/լոգիստիկա
5  /decide          →   3 սցենար յունիտ-էկոնոմիկա       →   🟢/🔴 որոշում + պլան
──────────────────────────────────────────────────────────────────────────────
```

## ՔԱՅԼ 1 — Նիշաների սքան (20–30 րոպե)

**Դու գրում ես.**
```
/niche-scan Автотовары
```

**Claude-ն անում է հերթականությամբ.**

| # | Գործողություն | Ինչու |
|---|---|---|
| 1 | `mpstats_client limit` | Ստուգում է՝ քանի հարցում է մնացել տարիֆում |
| 2 | `mpstats_client categories "Автотовары"` | Գտնում է **ճշգրիտ** path-ը (սխալ path = դատարկ պատասխան) |
| 3 | `niche_scan … --dry-run` | Ցույց է տալիս պլանը՝ 12 ենթա-նիշա, ~25 հարցում |
| 4 | **Կանգ առնում է և հարցնում քեզ** | Որ լիմիտը չվատնի առանց քո հաստատման |
| 5 | `niche_scan …` (իրական) | Ամեն նիշայի համար քաշում է մինչև 500 քարտ + 60 օրվա դինամիկա |
| 6 | Կարդում է `reports/niche_scan_*.md` | Բացատրում է հայերեն |

**Ինչ ես տեսնում.**
```
| # | Նիշա                  | Սքոր | Վերդիկտ   | Շրջ. 30օր  | ₽/քարտ  | Տոպ-10% | Աճ%  |
|---|-----------------------|------|-----------|------------|---------|---------|------|
| 1 | Органайзеры в багажник| 71.4 | 🟢 վերցնել| 8,420,000  | 142,000 | 38.2    | +24  |
| 2 | Держатели телефона    | 58.1 | 🟡 պահեստ.| 31,200,000 | 64,000  | 61.0    | +6   |
| 3 | Щётки для снега       | 44.3 | ❌ մերժել | 12,100,000 | 38,000  | 55.4    | -31  |
```
+ ամեն նիշայի քարտ՝ վաճառողներ, գնային միջանցք, կարծիքների բարիեր, կարմիր դրոշներ։

> 💡 №3-ը մերժվեց ոչ թե որովհետև փոքր է, այլ որովհետև **−31% ընկնում է** (սեզոնը փակվում է)։

## ՔԱՅԼ 2 — Կասկածի ստուգում (10 րոպե) ⚠️ ամենակարևոր քայլը

**Դու գրում ես.**
```
Վերցրու #1 նիշան և փորձիր ԽԱԽՏԵԼ այն։ Գտիր 5 պատճառ, թե ինչու սա կարող է
թակարդ լինել սկսնակի համար։ Ամեն պատճառի տակ դիր տվյալ data/raw/-ից։
```

**Ինչու է սա պարտադիր.** AI-ը լռելյայն համաձայնող է։ Այս պրոմպտը ստիպում է նրան
աշխատել **քո դեմ**, և հենց այստեղ են դուրս գալիս թաքնված խնդիրները.

```
1. Տոպ-3-ից 2-ը մեկ վաճառողի են (SEL_2291) → 29% շուկայից մեկ ձեռքում
2. Մեդիան կարծիք տոպ-20-ում = 340, բայց տոպ-5-ում = 1,900 → առաջին էջ մտնելը դժվար է
3. Գների ցրվածություն ×4.1 → նիշում խառնված են 600 ₽ և 2,800 ₽ ապրանքներ
4. Թարմ քարտերի 78%-ը FBS է → հնարավոր է լոկալ վաճառողների առավելություն
5. Չեմ կարող հաստատել սեզոնայնությունը — 30 օրվա տվյալը քիչ է, պետք է 12 ամիս
```

## ՔԱՅԼ 3 — Մրցակիցներ և ապրանքի բրիֆ (30–40 րոպե)

**Դու գրում ես.** `/sku-audit Органайзеры в багажник`

**Claude-ն ընտրում է 5 SKU ըստ տրամաբանության** (ոչ թե պատահական).
2 լիդեր + 1 միջին (վաճառում է քիչ կարծիքով) + 2 թարմ (<120 օր, արդեն վաճառում են)

Հետո՝ ամեն մեկի քարտ, դինամիկա, պաշարներ, **տոպ-20 բանալի բառ** և **կարծիքների վերլուծություն**.

```
Կրկնվող բողոքներ (78 կարծիքից).
| Բողոք                        | Հաճախ. | Մեր լուծումը              | +ինքնարժեք |
|------------------------------|--------|---------------------------|------------|
| Կպչուն ժապավենը թուլանում է  | 31%    | Վելկրո + ուժեղ ժապավեն    | +18 ₽      |
| Փոքր է, չի տեղավորվում       | 22%    | +5 սմ լայնություն         | +25 ₽      |
| Հոտ է գալիս բացելիս          | 14%    | Այլ նյութ (oxford 600D)   | +40 ₽      |
```

Սա արդեն **ապրանքի տեխնիկական առաջադրանք** մատակարարի համար։

## ՔԱՅԼ 4 — Իրական տարիֆներ WB-ից (5 րոպե)

**Դու գրում ես.** `/sync-tariffs Коледино`

Claude-ը քաշում է WB Seller API-ից՝ քո պահեստի ճշգրիտ լոգիստիկան, պահեստավորումը,
предмет-ի կոմիսիան, приёмка-ի ազատ օրերը → գրում է `config/tariffs_auto.yaml`։

```
Կոմիսիա «Органайзеры автомобильные»:  FBO 17.5% | FBS 19.0% | DBS 22.5%
Коледино: 1-ին լիտր 48 ₽ | +1 լ 15 ₽ | коэф 125% | պահեստ. 0.08 ₽/լ/օր
⚠️ Приёмка անվճար՝ 3, 5, 9 հոկտեմբերի (մյուս օրերին ×2–×4)
```

## ՔԱՅԼ 5 — Որոշում (20 րոպե)

**Դու գրում ես.** `/decide`

Claude-ը հաշվում է **3 սցենար** (ոչ թե մեկ լավատեսական թիվ).

```
                        ԲԱԶԱ      ՀՈՌԵՏԵՍ.    ԼԱՎԱՏԵՍ.
Գին                     1,490 ₽   1,270 ₽     1,640 ₽
Выкуп                   78%       63%         85%
ДРР                     15%       22%         10%
────────────────────────────────────────────────────────
Զուտ շահույթ / միավոր   398 ₽     112 ₽       585 ₽
Մարժա                   26.7%     8.8%        35.7%
ROI                      82%       23%        121%
ՎԵՐԴԻԿՏ                 🟢        🟡 սահման   🟢

Առաջին խմբաքանակ՝ 215 հատ (104,500 ₽), շահույթ ~85,000 ₽
Kill criteria՝ եթե 30 օրում <30 վաճառք ԿԱՄ ДРР >30% → երկրորդ խմբաքանակ չենք գնում
```
