# Ապրանք ընտրելու չեկ-լիստ ($2,000 բյուջե, WB, նոր վաճառող)

Տպիր/պահիր բաց։ Ամեն փուլ ունի **անցման պայման** — չբավարարելու դեպքում վերադառնում ես նախորդ քայլ,
ոչ թե «փորձում ես հուսալ»։

---

## Փուլ 1. Նիշաների ցանկ (1 օր)
- [ ] 3–5 ծնող կատեգորիա, որտեղ ունես գոնե նվազագույն հասկացողություն
- [ ] `niche_scan --children categories --top 12` ամեն մեկի վրա
- [ ] Դուրս ես նետում այն ամենը, ինչ ունի կոշտ ֆիլտրի fail

**Անցում.** ≥5 նիշա սքորով ≥65

## Փուլ 2. Ֆիզիկական ֆիլտր (30 րոպե, առանց տվյալների)
Դուրս նետիր, եթե ապրանքը՝
- [ ] >1.5 լ ծավալ կամ >1 կգ (լոգիստիկան ուտում է մարժան)
- [ ] փխրուն է (ապակի, կերամիկա) — վերադարձներ + բրակ
- [ ] չափսեր ունի (հագուստ/կոշիկ) — выкуп 30–45%, մնացորդների ռիսկ
- [ ] էլեկտրոնիկա երաշխիքով, սննդամթերք, կոսմետիկա (ժամկետ + սերտիֆիկատ)
- [ ] պահանջում է «Честный знак» մարկիրովկա — սկսնակի համար ավելորդ բարդություն
- [ ] ակնհայտ սեզոնային է, և սեզոնը 2 ամսից փակվում է

**Անցում.** 3–5 նիշա

## Փուլ 3. Մրցակցային ռեալիզմ (2–3 ժամ)
- [ ] `sku_audit` 5 SKU-ի վրա (2 լիդեր, 1 միջին, 2 թարմ)
- [ ] Կա՞ գոնե 2 քարտ <120 օր, որ արդեն վաճառում է ≥30 հատ/ամիս
- [ ] Տոպ-3-ը մեկ վաճառողի՞ն է պատկանում → մերժել
- [ ] Կարծիքներից հանված ≥3 կոնկրետ թերություն, որ մենք կուղղենք
- [ ] SEO. ≥10 բանալի բառ, որոնցով լիդերները ինդեքսավորվում են

**Անցում.** 2–3 նիշա + ապրանքի բրիֆ

## Փուլ 4. Մատակարար (2–5 օր)
- [ ] ≥3 գնային առաջարկ (1688 / Alibaba / տեղական / ՌԴ մեծածախ)
- [ ] Ինքնարժեքը ≤ մեդիան գնի 35%-ը
- [ ] MOQ-ն տեղավորվում է բյուջեի ապրանքային մասում (~$1,100)
- [ ] Lead time ≤ 30 օր, նմուշ պատվիրված
- [ ] Փաստաթղթեր (сертификат/отказное) մատակարարից հասանելի են

**Անցում.** 1–2 նիշա փաստացի ինքնարժեքով

## Փուլ 5. Յունիտ-էկոնոմիկա (1 ժամ)
- [ ] `unit_econ` նիշայի **մեդիան** գնով → մարժա ≥18%, ROI ≥60%
- [ ] Սցենար «գին −15%» → մարժան մնում է դրական
- [ ] Սցենար «выкуп −15 տոկոսային կետ» → մարժան մնում է դրական
- [ ] ДРР 15–20% ստարտի համար (ոչ 8%)
- [ ] Break-even գինը ≥20% ցածր է շուկայի մեդիան գնից

**Անցում.** 1 ապրանք

## Փուլ 6. Ֆինանսական պլան
- [ ] Ապրանք ~55% ($1,100) / գովազդ+կոնտենտ ~25% ($500) / ռեզերվ ~20% ($400)
- [ ] Խմբաքանակը ≥80 միավոր (ավելի քիչով քարտը ալգորիթմ չի հավաքում)
- [ ] Հաշվարկված է, քանի օրում է վաճառվում խմբաքանակը նիշայի միջին տեմպով
- [ ] Երկրորդ խմբաքանակի փողը հայտնի է, որտեղից է գալու

## Փուլ 7. Մեկնարկ և kill criteria
- [ ] 30 օրվա թիրախներ. օրական վաճառք, ДРР, կարծիքների քանակ, CTR
- [ ] **Kill criteria** (օրինակ). եթե 30 օրում <25 վաճառք ԿԱՄ ДРР >35% → երկրորդ խմբաքանակ չենք գնում
- [ ] Ամենշաբաթյա `niche_scan` նույն նիշայի վրա՝ դինամիկան հետևելու համար

## Անմիջական մերժման կարմիր դրոշներ 🚩

1. Տոպ-10-ը վերցնում է >78% շրջանառության
2. Մեկ վաճառողը >45%
3. Տոպ-20-ի մեդիան կարծիքները >800
4. Տոպ-50-ում թարմ (<120 օր) քարտեր չկան կամ <5% են
5. Նիշան ընկնում է >20% ամսական
6. Գների ցրվածությունը >×6 (նիշան սխալ է սահմանված)
7. Մեդիան գինը <700 ₽ (լոգիստիկան ուտում է ամեն ինչ) կամ >3,500 ₽ (բյուջեն չի հերիքում)
8. Ապրանքը պահանջում է մարկիրովկա/սերտիֆիկացիա, որը չես կարող արագ ապահովել
