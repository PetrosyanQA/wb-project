# Проверка анализа (обязательна перед любым выводом)

Проверь вывод или отчёт по списку ниже **до** того, как отдать его пользователю.
Каждая ловушка здесь — реальная ошибка проекта (дата в скобках). Ответ — на языке пользователя.

## 1. Источник и смысл каждой цифры
Для каждой цифры, на которой держится решение, назови файл/запрос и метку **[факт] / [оценка] / [допущение]**. Цифра без источника → «—» и почему (CLAUDE.md, правило 1).

| # | Ловушка | Как проверить |
|---|---|---|
| 1 | Saleflow `keywords`: `count` — частота **точного написания**, а не число товаров; спрос = `wb_count` (23.10: «137 товаров» по ножам было ошибкой) | Нигде не делить `wb_count / count` как «дефицит» |
| 2 | Живая выдача (`wb_check_rates`): до 300–480 из 500 — реклама (`promoted`); слабые карточки в топ-30 — платные новички (24.10: «маленькая сумка» снята) | Считать конкуренцию только по органике (`promoted == false`) |

| 4 | Evirma: в истории `spp_fbs` — **минимум** среди карточек, типичная — `spp` полосы (25.10: «27 против 6 %» было неверным прочтением) | Брать `spp` полосы для нашей цены продавца |
