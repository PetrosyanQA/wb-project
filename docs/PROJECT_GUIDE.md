## 4. Как работает отбор товара (воронка)

Фильтры идут **от бесплатных к платным** и останавливаются на первом провале
(пороги — `config/filters.yaml`, код — `src/gates.py`):

| # | Фильтр | Стоимость | Убивает нишу, если |
|---|---|---|---|
| 1 | Регуляторика | 0 | «Честный знак», сертификация, батарейки, магниты (правило пользователя) |
| 2 | Экономика | 0 | цена вне 1 000–2 500 ₽, объём > 1 л, логистика > 25 % цены, маржа < 18 % |
| 3 | Концентрация | 1 запрос | top-10 > 40 %, top-1 > 25 %, < 8 продавцов в top-20 |
| 4 | Динамика | 1 запрос | пиковый месяц год к году < −5 % |
| 5 | Профиль | 0 | не плато, < 30 продавцов |
| 6 | Аудит конкурентов | ≈ 20 | только для выживших |

Дальше по выжившим:
1. **Реальная цена закупки** — 1688 через Bright Data.
2. **Реальные габариты и вес** — карточки WB, Saleflow `package_*`.
3. **Отзывы конкурентов** — какую жалобу мы исправим.
4. **Подтипы и поиск за 12 месяцев** — какой именно вид товара растёт.
5. **Юнит-экономика при медианной цене**, а не при мечте.
6. **Решение**: 1 товар + 2 запасных, с правилом остановки.

Ключевые уроки, вшитые в метод:
- **Ошибка выжившего**: в топе видны только победители → сравниваем с контрольной группой провалившихся новичков.
- **СПП**: цены в Saleflow — это цены покупателя (со скидкой WB). У AM-кабинета СПП ≈ 0 → наша цена = цена покупателя.
- **Сезон считаем по подтипу**, а не по всей нише (вся 249 — пик в феврале, лента для турника — пик летом).
- Правило «медиана новичков ≥ 4/день» отсеивало 95 % ниш — ослаблено (`niche_relaxed_2026-10-18`).

## 5. Как считается прибыль

Код: `src/unit_econ.py`, схема бизнеса: `config/scheme_am_fbs.yaml`, карго: `src/cargo.py`.

Формула на 1 продажу:
**Прибыль = Цена − Комиссия WB − Эквайринг − Логистика (с невыкупами) − Возвраты − Реклама − Налог − Себестоимость**

| Статья | Значение | Источник |
|---|---|---|
| Комиссия FBS (Эспандеры) | **21 %** | [факт] WB API `kgvpMarketplace` |
| Логистика WB FBS | 78,2 ₽ до 1 л + 23,8 ₽/л сверх | [факт] WB API тарифы |
| Фулфилмент | 30 ₽ за отправку | [пользователь] |
| Выкуп | 82 % (невыкупы тоже платим) | [факт] Saleflow |
| Возврат невыкупа | 50 ₽ | [допущение] |
| Реклама (ДРР) | 15 % от заказов (старт 25 %, зрелость 10 %) | [оценка] |
| Налог | 10 % от выручки (ИП Армения) | [пользователь] |
| Эквайринг | 1,5 % | [допущение] |
| Себестоимость | ¥ × 12,43 ₽ + карго коробки / шт + упаковка 50 ₽ + 25 ₽, + 3 % брак | [факт] курс ЦБ, калькулятор YUANEXIM |

Пример: чёрная 22 мм за 1 100 ₽:
- комиссия 231;
- эквайринг 17;
- логистика с невыкупами 143;
- реклама 201;
- налог 110;
- себестоимость 176;
- **прибыль ≈ 222 ₽ (20 %)** [оценка].

Порог проекта: маржа ≥ 18 % и ROI ≥ 60 %.

## 10. Правила проекта (коротко)

1. Не выдумывать чисел: всё — из данных или из расчёта, иначе «—».
2. Метки [факт] / [оценка] / [допущение]; период под каждой таблицей.
3. Ключи — только в `.env`. Ключ, попавший в чат, — удалить и создать новый.
4. В git не попадают `.env`, `.mcp.json`, `data/raw`.
5. Любое действие в **реальном кабинете WB** (карточка, цена, остатки, реклама, ответы) — только после «да» владельца.
6. Не обходить защиту сайтов и систему разрешений Claude Code.
7. Без «Честного знака», магнитов и батареек.
8. Самовыкупы — нет; отзывы — через «Отзывы за баллы».
9. Отчёты в файлах — на армянском, ответы в чате — на языке владельца; полный текст отчёта — в чат, файл — копия.
