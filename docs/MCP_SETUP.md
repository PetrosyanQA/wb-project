# MPStats-ը որպես MCP գործիք Claude Code-ում (ոչ պարտադիր)

Երկու ճանապարհ կա, և դրանք **փոխլրացնող** են.

| | Սկրիպտներ (այս պրոյեկտը) | MCP սերվեր |
|---|---|---|
| Ում է պատկանում տրամաբանությունը | քեզ՝ ֆայլերում, վերարտադրելի | մոդելին՝ ամեն անգամ նորից |
| Սքորինգ, յունիտ-էկոնոմիկա | ✅ ֆիքսված բանաձևեր | ❌ ձեռքով |
| Ճկուն հարցեր («ցույց տուր այս բրենդի դինամիկան») | ⚠️ պետք է `raw` կանչ | ✅ բնական |
| API լիմիտի վերահսկում | ✅ քեշ + dry-run | ⚠️ հեշտ է այրել |

**Խորհուրդ.** որոշման խողովակաշարը պահիր սկրիպտներում, MCP-ն ավելացրու ad-hoc հարցերի համար։

---

## Տարբերակ 1 — առանց MCP (լռելյայն)

Ոչինչ պետք չէ։ Claude Code-ը կանչում է Bash-ով.
```bash
python -m src.mpstats_client raw category/brands --post --param path="Дом/Кухня" --param d1=2026-08-01 --param d2=2026-08-31
```
Սա ամենաապահով տարբերակն է՝ թոքենը մնում է `.env`-ում, ամեն կանչ քեշավորվում է։

## Տարբերակ 2 — համայնքային MCP սերվեր

Կա բաց կոդով MCP սերվեր MPSTATS API-ի վրա՝ `github.com/snsudak/mpstats-mcp`
(գործիքներ՝ `mpstats_categories`, `mpstats_category`, `mpstats_sku`, `mpstats_similar`,
`mpstats_forecast`, `mpstats_request` և այլն)։

```bash
pip install "fastmcp>=2.12,<3" "httpx>=0.27" "uvicorn>=0.30"
export MPSTATS_TOKEN=...
python server.py            # լոկալ, http://localhost:8000

# Claude Code-ում
claude mcp add --transport http mpstats http://localhost:8000/mcp
```

⚠️ **Անվտանգություն.** սա երրորդ կողմի կոդ է, որին տալիս ես քո MPStats թոքենը։
Կարդա `server.py`-ն նախքան գործարկելը, մի՛ բացիր էնդփոյնթը ինտերնետ առանց գաղտնի ուղու,
և առանձին թոքեն օգտագործիր, եթե հնարավոր է։

## Տարբերակ 3 — MPStats-ի պաշտոնական MCP

MPStats-ն ինքը հայտարարել է MCP-ինտեգրացիա («Подключите MPSTATS к своему AI-агенту»)։
Եթե այն հասանելի է քո տարիֆում, նախընտրիր այն համայնքային սերվերից՝ թոքենը չի հեռանում
պաշտոնական պերիմետրից։ Ստուգիր mpstats.io-ի ինտեգրացիաների բաժնում։
