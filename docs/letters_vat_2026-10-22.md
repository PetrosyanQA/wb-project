# Письма про НДС и налог (2026-10-22)

## 1. В поддержку WB
Где: портал WB Партнёры → **Помощь / Обращения** → «Создать обращение» → тема «Финансы / Налоги» (или «Другое»).

```
Здравствуйте!
Я продавец из Армении (ИП, кабинет WB Армения), планирую продавать по модели FBS (Маркетплейс)
со своего склада в Московской области покупателям в России. Товар — эспандер (лента для подтягивания), без маркировки.

Прошу ответить:
1. Удерживает ли Wildberries с моих продаж покупателям в РФ НДС по статье 174.3 НК РФ
   (расчётная ставка 22/122) сверх коэффициента вознаграждения / коэффициента выкупной цены?
   Или этот налог уже входит в коэффициент и отдельно с меня не удерживается?
2. Какой коэффициент вознаграждения (КВЦ) действует для предмета «Эспандеры» для моего кабинета
   по модели FBS? В API тарифов вижу kgvpMarketplace = 21 % — это и есть полная ставка?
3. Применяется ли к моим товарам скидка WB (СПП) для покупателей?
4. Какие ещё удержания будут в отчёте, кроме коэффициента, логистики и рекламы?

Спасибо!
```

## 2. Бухгалтеру (Армения)

```
Здравствуйте! Я ИП в Армении, начинаю продавать на Wildberries (Россия).
Схема: покупаю товар в Китае (1688, без таможенных документов, доставка карго в Москву),
храню на складе фулфилмента в Подмосковье, продаю покупателям в России через WB.
WB Армения выкупает у меня товар (уведомление о выкупе, ЭСФ в течение 5 рабочих дней).
Ожидаемый оборот первого года — 1,5–3 млн ₽ (≈ 7–14 млн ֏).

Вопросы:
1. Могу ли я работать как микропредприятие (налог 0 %, оборот до 24 млн ֏)? Нет ли запрета для торговли / продаж через WB?
2. Если нет — налог с оборота 10 %: могу ли уменьшить его на расходы без документов о закупке (1688, карго)?
3. Какие документы нужны, чтобы закупка в Китае и карго считались расходами?
4. Нужно ли что-то платить или подавать в Армении при выкупе товара WB Армения?
```

После ответов — внести в `config/scheme_am_fbs.yaml` (`vat_ru_eaeu_pct`, `tax.rate_pct`) и пересчитать
`reports/economics_249_2026-10-22.md`.
