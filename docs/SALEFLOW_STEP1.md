# Saleflow — քայլ 1. ի՞նչ գործիքներ ունի

Մենք դեռ չգիտենք Saleflow-ի API մակերեսը (փաստաթղթեր չկան, sandbox-ը չի հասնում)։
Առաջին հարցումը պետք է **քարտեզագրի գործիքները** — դրանից հետո ես կգրեմ ճշգրիտ
հուշումներ ամեն դարպասի համար։

---

## 📋 Հուշում 1 — գործիքների ցանկ

Պատճենիր սա **Claude Desktop**-ի նոր չատում (saleflow connector-ը միացված).

```
Покажи полный список инструментов MCP-сервера saleflow.

Для каждого инструмента верни: name, description и полную JSON-схему входных
параметров (inputSchema) — какие поля обязательные, какие опциональные,
какие значения допустимы.

Ответ дай ТОЛЬКО одним JSON-блоком, без пояснений, в формате:
{"tools":[{"name":"...","description":"...","inputSchema":{...}}]}
```

Պատասխանը բեր այստեղ կամ ուղիղ ներմուծիր.

```bash
python3 -m src.saleflow ingest - --tool tools_list --note "API մակերես"
```

---

## 📋 Հուշում 2 — առաջին իրական տվյալը

Գործիքների ցանկը տեսնելուց հետո այս հուշումը կճշտվի։ Առայժմ՝ ունիվերսալ տարբերակ.

```
Используя saleflow MCP, найди на Wildberries подкатегории, подходящие под профиль:

• цена товара: 1400–2600 ₽
• объём товара: до 1 литра (компактный, лёгкий)
• продавцов в нише: больше 50 (не монополия)
• доля топ-10 продавцов: меньше 40%
• доля топ-1 продавца: меньше 25%
• спрос стабильный или растущий год к году (не сезонный всплеск)
• средний рейтинг в нише: ниже 4.6 (есть что улучшить в товаре)

Верни 15–20 подкатегорий. Для каждой: название, путь категории, месячная
выручка ниши, число продавцов, число SKU, средняя цена, медианная цена,
доля топ-10, доля топ-1, средний рейтинг, среднее число отзывов,
динамика год к году в %.

Ответ дай ТОЛЬКО одним JSON-блоком, без текста до и после.
```

```bash
python3 -m src.saleflow ingest - --tool niches --note "առաջին սկան 1400-2600₽"
```

## Ինչու՞ հենց այս ֆիլտրերը

| Ֆիլտր | Որտեղից | Պատճառ |
|---|---|---|
| 1400–2600 ₽ | `filters.yaml` + landed cost | Երևանի լոգիստիկան 2× է; ցածր գնով մարժա չի մնում |
| ≤1 լ | տարիֆային աստիճաններ | >1 լ դեպքում լոգիստիկան թռչում է |
| >50 վաճառող | `gates.py` | ապացուցված պահանջարկ, ոչ թե դատարկ նիշա |
| տոպ-10 <40% | `filters.yaml` | մոնոպոլ նիշա նոր վաճառողին տեղ չի տա |
| տոպ-1 <25% | `filters.yaml` | մեկ գերիշխող բրենդ = փակ դուռ |
| YoY ≥0 | որոշում | ամսական աճը աղմուկ է, տարեկանը՝ ազդանշան |
| ռեյտինգ <4.6 | թիրախ պրոֆիլ | «սարահարթ + լուծելի բողոք» = մուտքի կետ |

Չինաստանից գնելու սահմանը՝ **¥8–25** գործարանում (ավելի թանկը ≤2600₽-ում չի անցնում
Երևանի տարիֆներով) — տես `reports/decide_market_checklist.md`։

## Ի՞նչ եմ անելու ստանալուց հետո

1. `ingest` → հում JSON՝ `data/raw/saleflow/`-ում (վերագործարկելի ապացույց)
2. `normalize` → ստուգում, թե որ դաշտերն են ճանաչվել; անհրաժեշտության դեպքում
   ալիասներ `src/fields.py`-ում
3. `gates.py` → էժան դարպասները ըստ արժեքի (regulatory → concentration → economics)
4. `unit_econ` + `landed_cost` → ամեն թեկնածուի իրական մարժան Երևանից
5. Վերդիկտային աղյուսակ՝ 🟢 ≥65 / 🟡 ≥50 / ⚪️ <50
