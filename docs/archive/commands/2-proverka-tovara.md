Проверь выбранный товар: **$ARGUMENTS** (ниша и товар; по умолчанию — текущее решение в `PROJECT_STATE.md`).
Отвечай на языке пользователя; полный отчёт — в чате, файл — копия в `reports/`. Ничего не меняй в кабинете WB без «да» пользователя.

## А. До закупки
1. **Конкуренты.** 5 карточек точного типа: 2 лидера, 1 середина с малым числом отзывов, 2 новичка < 120 дней.
   По каждой: цена покупателя, продажи/мес, отзывы, рейтинг, реклама (`wb_sku by_period` в Saleflow), остатки.
   Доля одного продавца в точном подтипе — если > 25 %, сказать прямо.
2. **Жалобы.** Отзывы WB по точному типу (`src.niche_monitor.feedbacks`): темы негатива в % → что исправляем в товаре и карточке.
3. **СПП и цена.** `python -m src.evirma show <id>` + облачный мониторинг (`cloud_state/last.json`, отчёт в Telegram).
   Цена продавца выше границы верхней полосы СПП, но покупатель видит не дороже потолка из решения.
4. **Тарифы и комиссия.** `python -m src.wb_seller commission --subject "<предмет>"`; при необходимости
   `python -m src.sync_tariffs --warehouse "<склад>" --subject "<предмет>" --apply`.
5. **Экономика и деньги.** `src/unit_econ.py` по **котировке** поставщика (не по целевой ¥); `python -m src.budget_sim` — P25/P50/провал.
6. **Поставщик.** КП «под ключ» за единицу: ТН ВЭД, НДС, вес, короб, срок. Образцы и тест качества.
7. **Премортем + проверка анализа.** «Через 6 месяцев провалились — почему?» → топ-3 причины → проверки до оплаты
   (пример: `reports/premortem_249_band_set_2026-10-26.md`); пройди `docs/ANALYSIS_CHECKLIST.md`.

## Б. После старта продаж (когда есть карточка и ключ WB)
8. **Реальность против плана:** `python -m src.wb_facts buyout --days 30`, `funnel --days 30 --nm <id>`, `regions`;
   фактические выплаты против `unit_econ`. Каждое расхождение > 5 % — объяснить и заменить допущение фактом.
9. **Kill-критерии** из решения: стоимость заказа, ДРР, выкуп, отзывы «порвалась/брак».

## Ответ
Таблица «✅ / ⚠️ / ❌» по пунктам, что изменилось в экономике (было → стало), решение: **платим / ждём / меняем товар**,
и не больше 3 действий на 7 дней, по влиянию на деньги. Конец — «Следующий шаг:».
