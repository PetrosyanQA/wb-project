Проверь вывод или отчёт **$ARGUMENTS** (или последний вывод в разговоре) по списку ниже **до** того, как отдать его пользователю.
Каждая ловушка здесь — реальная ошибка проекта (дата в скобках). Ответ — на языке пользователя.

## 1. Источник и смысл каждой цифры
Для каждой цифры, на которой держится решение, назови файл/запрос и метку **[факт] / [оценка] / [допущение]**. Цифра без источника → «—» и почему (CLAUDE.md, правило 1).

| # | Ловушка | Как проверить |
|---|---|---|
| 1 | Saleflow `keywords`: `count` — частота **точного написания**, а не число товаров; спрос = `wb_count` (23.10: «137 товаров» по ножам было ошибкой) | Нигде не делить `wb_count / count` как «дефицит» |
| 2 | Живая выдача (`wb_check_rates`): до 300–480 из 500 — реклама (`promoted`); слабые карточки в топ-30 — платные новички (24.10: «маленькая сумка» снята) | Считать конкуренцию только по органике (`promoted == false`) |
| 3 | Продажи Saleflow после **2026-07** неполные; поле СПП за октябрь = 0 у всех | Брать полные месяцы ≤ 31.07.2026 и указывать период под таблицей |
| 4 | Evirma: в истории `spp_fbs` — **минимум** среди карточек, типичная — `spp` полосы (25.10: «27 против 6 %» было неверным прочтением) | Брать `spp` полосы для нашей цены продавца |
| 5 | Граница полос СПП в нише может сдвигаться **в течение дня** (249: 2 200 → 1 900 ₽; 31 → 29 → 20 → 24 %) | ≥ 2 замера в разные дни; цена — с запасом выше границы; облачный мониторинг `src/cloud_daily.py` |
| 6 | Кривые продаж новичков из топ-500 — только выжившие | Планировать по P25–P50; сценарий «провал» с ДРР 40 % |
| 7 | Всплеск поиска из-за новостей ≠ тренд (канистры 2026: паника из-за бензина, 97 % новых карточек без продаж) | Проверить новости (Exa) и форму ряда: ступенька за неделю = событие |
| 8 | «Новый» запрос в сравнении год к году = не попал в топ-5 000 прошлого года, а не рост | Требовать базу ≥ 1 000 поисков |
| 9 | Июльские данные завышают летние и занижают зимние товары | Сверить спрос с декабрём/свежим месяцем и с датой приезда товара |

## 3. Перед отправкой
- Есть ли альтернативное объяснение главного вывода? (если установлен — `/thinking-pre-mortem` или `/thinking-map-territory`)
