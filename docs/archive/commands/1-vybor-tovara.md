Пользователь ещё не выбрал товар. Найди его: **$ARGUMENTS** (пожелания или ограничения, если есть).
Отвечай на языке пользователя; полный отчёт — в чате, файл — копия в `reports/`.

Правила пользователя (жёсткие) — в `CLAUDE.md` и памяти: бюджет $2 000, армянский кабинет FBS, только белый импорт YUAN EXIM,
маржа по цене продавца, налог 10 %, нет «Честного знака» / магнитов / батарей / электроники, декларации — не проблема,
сравнение по **общей прибыли** (прибыль/шт × объём, оборот капитала), а не по % маржи.

## Шаги (дешёвое — сначала)
1. **Запреты, 0 запросов.** `data/processed/niche_requirements_*.json` (последний): убрать ЧЗ, электронику, батареи, магниты,
   громоздкое, жидкости. ЧЗ — по коду ТН ВЭД.
2. **Деньги и цена, 0 запросов.** Выручка ниши, медиана цены, продавцы; белый импорт выдерживает только цену покупателя ≳ 1 000–1 500 ₽ (лёгкий товар).
3. **Спрос.** Поисковые запросы: `python -m src.seo_gap analyze` и `python -m src.seo_gap growth` (рост год к году ≥ ×2, база ≥ 1 000).
   Новые ниши — `python -m src.seo_gap collect --month <YYYY-MM>` (1 запрос Saleflow на нишу; лимит 500/день — следи).
4. **Рынок ниши (Saleflow, топ-500 за последний ПОЛНЫЙ месяц ≤ 07.2026).** Концентрация (топ-1 ≤ 25 %, в т.ч. в точном подтипе),
   новички P25/P50 по месяцам, ценовые сегменты. Сбор: `python -m src.strategy_collect --niche <id> --step core`.
5. **Живая выдача — только органика** (`promoted == false`): слабые карточки без рекламы = шанс; реклама наверху ≠ дыра.
6. **СПП:** `python -m src.evirma show <id>` — поле `spp` полосы для нашей цены продавца, минимум 2 замера в разные дни.
7. **Китай:** реальные ¥ (1688 / Yiwugo / КП), вес, короб → `src/unit_econ.py` (схема `am_fbs`, комиссия из WB API:
   `python -m src.wb_seller commission --subject "<предмет>"`).
8. **Жалобы:** отзывы WB по точному типу товара (`src.niche_monitor.feedbacks`) → одна исправимая жалоба.
9. **Деньги за 6 месяцев:** `python -m src.budget_sim` (сценарии P25/P50/P75/провал, бюджеты).
10. **Проверка анализа:** пройди `docs/ANALYSIS_CHECKLIST.md` (15 пунктов) и **премортем**: «через 6 месяцев провалились — почему?» → топ-3 причины → проверки.

## Ответ
**1 товар + 2 запасных**, по каждому: метрики ниши с периодом, почему лучше по общей прибыли, таблица экономики,
план партии на $2 000, топ-3 риска, kill-критерии на 30-й день, жалоба, которую исправляем; блок «Проверка анализа» (✅ / ⚠️).
