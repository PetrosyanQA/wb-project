# НОВЫЙ ПЛАН: найти нишу лучше кистей (решение пользователя 02.11.2026)

Пользователь: «надо найти другую нишу лучше кисточек». Режим проекта → **DISCOVERY**.
Кисти с подписями (премиум ≈ 2 690 ₽) остаются **текущим кандидатом и планкой**: новый товар должен быть лучше, иначе продаём кисти.
КП и образец кистей можно запрашивать параллельно — это ни к чему не обязывает.

## Планка «лучше кистей» (все условия сразу)
| Критерий | Планка (кисти премиум) | Источник |
|---|---|---|
| Прибыль в месяц = продажи новичка P50 × прибыль/шт (СПП по Evirma, ДРР 15 %, партия 300) | **> 80 тыс. ₽/мес** | `src/unit_econ`, `datastore.products` (июль) |
| Уникальность | **SUPPORTED**: за рубежом продаётся (ASIN с продажами) + на WB нет сильных аналогов **+ на WB есть спрос** | Bright Data / Apify + `wb_check_rates` |
| Монополия в сегменте | топ-6 ≤ 60–65 % на ≥ 40 карточках | `niche_inside --month 2026-10` |
| Документы | понятные, без магнитов (ЧЗ / декларация — с ценой и сроком) | `niche_requirements`, Exa |
| Риск убытка | ≤ 10 % (`monte_carlo --seed 1`) | `config/monte_carlo.yaml` |
| Решение | `python -m src.decision` не хуже, чем у кистей | `config/decision_current.yaml` |

## Шаги и бюджет
| # | Шаг | Чем | Стоимость |
|---|---|---|---|
| 1 | **Докачать несобранные ниши** очереди (89 из 571) | `python -m src.niche_deep scan <id…> --products-only` | ≈ 89 запросов Saleflow |
| 2 | **Пересчитать отбор** всех ниш (свежая СПП Evirma, комиссия кабинета, запрет только магниты) | `python -m src.screen_white --top 60` | 0 |
| 3 | **Очередь кандидатов**: прошли экономику, ≥ 15 карточек в сегменте, ещё не проверялись (сейчас 41 — `data/processed/niche_queue_2026-11-02.json`) → разбор внутри, топ-15 | `python -m src.niche_inside <id> --month 2026-10` | 0 |
| 4 | **Уникальность** для топ-10: Amazon (что продаётся, новинки) → 2–3 русские формулировки в живой выдаче WB, только органика, **проверка спроса WB** | Bright Data `fetch` (≈ 30 кредитов), `wb_check_rates` (≈ 25 запросов) | ≈ 30 кредитов + 25 запросов |
| 5 | **Жалобы** покупателей для 3–5 прошедших (одна тема ≥ 12 %, которую исправим) | `python -m src.product_deep <id> …` (в фоне — долго) | 0 |
| 6 | **Цена в Китае** (карточка оффера, нужная комплектация) и **факты кабинета** (комиссия предмета, тарифы) для 3 лучших | `brightdata_client s1688/d1688`, `wb_seller commission / box` | ≈ 10 кредитов + 3 запроса WB |
| 7 | **Экономика + риск + решение** против кистей | `unit_econ`, `monte_carlo --sensitivity`, `src.decision` | 0 |
| 8 | **Итог**: 1 товар + 2 запасных — или честно «кисти остаются лучшими» | отчёт `reports/new_niche_<дата>.md`, learning (прогнозы и уроки) | 0 |

Итого: Saleflow ≈ 120 запросов (1 день, запас ≥ 50), Bright Data ≈ 40 кредитов, Apify — по необходимости (стоп < 0,5 USD).

## Что уже известно (не повторять)
- Отклонено: корректор осанки (гиганты), 804 «раскрась ночник / ткацкий станок / стразы / террариум» (на WB нет спроса), фотоальбомы baby book / скрап-крафт (нет спроса), наколенники, подарочные боксы, фигурки (ИС), ножи, кошельки, сумки (выкуп 51 %).
- Сильные, но без уникального варианта: **804 Наборы для поделок**, **235 Фотоальбомы (семейные)** — вернуться, если найдётся «подписанный» вариант (как у кистей).
- По одному только отбору лучше кистей проходят немногие (301 Цепочки — 23 карточки, ¥max низкий; 1302 Мячи — сезонность зимой 0,65) → главный шанс — несобранные 89 ниш и уникальный вариант внутри уже сильных ниш.

## Правила
- Начинать с бесплатного (шаги 2, 3, 5), потом платное; перед платным — сказать расход.
- Хит Amazon без спроса на WB — не кандидат (урок 02.11, трижды).
- Цифры прибыли — только пересчётом текущей моделью; октябрь Saleflow — с пометкой «неполные».
- Каждый вывод — прогноз в `learning/predictions.csv`, каждая ошибка — урок в `learning/LESSONS.md`.

Следующий шаг: завтра (лимит Saleflow 500) — шаг 1 (докачать 89 ниш) и шаг 2 (пересчёт отбора).
