# Как проект учится

| Файл | Что | Кто пишет |
|---|---|---|
| `LESSONS.md` | уроки: ошибка → правило → где защищено | конец каждого анализа (`src.learning lesson`) |
| `predictions.csv` | проверяемые прогнозы (СПП, выкуп, продажи новичка, ¥…) и факты; ошибка в % | `src.learning predict` / `fact` |
| `spp_history.csv` | СПП Evirma по нишам наблюдения каждый день при ценах 1 400 / 1 700 / 2 300 / 3 000 ₽ | `src.learning daily` (бесплатно) |
| `cohort_437.csv` | судьба новичков ниши кистей: продажи в день, цена, отзывы, реклама | `src.learning daily` (из утреннего отчёта, бесплатно) |

Цикл: **прогноз → факт → ошибка → множитель для следующих прогнозов → урок**. `python -m src.learning review` показывает, на сколько мы систематически ошибаемся по каждому виду прогноза.
